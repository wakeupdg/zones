## Pitfalls for T13

- The thread is kept alive by its sources alone; a run loop with no sources makes `CFRunLoopRun` return immediately (documented CF behaviour, not exercised here). Add the observer source in `setup` before `CFRunLoopRun`.
- The AXObserver `refcon` is unretained in the probe; the owner must outlive the observer.
- AX and CF reference types are not Sendable; T13 needs one boxed hand-off to the thread (the probe uses `UncheckedBox`).
- The 60 s idle was main sleeping while the observer thread blocked in its run loop; the AX target app was not backgrounded or hidden.

## Dependent ACs
