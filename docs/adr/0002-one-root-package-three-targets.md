# One root Package.swift with ZonesCore, ZonesLayout, ZonesWindowing

All logic is in one root `Package.swift` with three library targets (`ZonesCore` shared types and persistence, `ZonesLayout` layout math and templates, `ZonesWindowing` AX/CG window services behind protocols) plus test targets and `ZonesTestSupport`. The app target lives under `App/` and is generated by XcodeGen from `project.yml`, depending on the local package. One `swift test` from the root runs every logic test headless. Rejected: three separate packages (more plumbing, no benefit at this size).
