# T67: Span Zone numbers after a topology change during a drag

Kind: fix (v0.1.1, CHANGELOG 0.1.0 known issue from the T39 review). Blocked by: none.

## Known issue
After a topology change during a drag (a display is added, removed or rearranged while the Activation Modifier drag is live), Span Zone numbers come from the old Layout; a number missing from the new Layout shrinks the drop rectangle silently.

## Goal
1. Reproduce it in a pure test (SpanLogic / drag reducer inputs: span set from Layout A, then the topology changes to Layout B).
2. Decide the correct behavior from the spec (LOCKED-SPEC: Span, topology change, drag). Likely: on a topology change mid-drag, re-resolve the span set against the new Layout or cancel the span; never a silent shrink. If the spec does not say, ask DG with 2 options.
3. Fix test-first.
