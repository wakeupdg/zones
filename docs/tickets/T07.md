## ADRs

- ADR-0022: Frame writes go size, position, size; read back; toggle AXEnhancedUserInterface off during the write. Amendment 2026-10-24 (C6): restore Enhanced UI in a defer on every path; skip the toggle when the attribute is absent or already off; keep a once-per-app recovery record with the prior value; policy `toggle` (default) or `leave`.
- ADR-0025: Dev builds are signed with a stable self-signed "Zones Dev" identity. Amendment 2026-10-24 (AC-014): `scripts/release.sh --dry-run` prints one stderr line containing "ad-hoc" when `ZONES_SIGN_IDENTITY` is unset (T38 owns it, not this ticket).
- ADR-0015: All AX calls run on a dedicated WindowActor with a 250 ms messaging timeout. Amendment 2026-10-24 (C7): a second consecutive timeout against the same app aborts the current Snap sequence (one retry only), so a hung app costs at most 0.5 s; the app then enters an unresponsive cooldown.

## WriteProbe design

- CLI: `WriteProbe --bundle <id> | --pid <n>  --target x,y,w,h  [--policy toggle|leave]  [--runs N]  [--json]  [--trust]`.
- `--trust` prints `AXIsProcessTrusted()` and exits (used for the SPK-005 stand-in, see slice 2).
- Per run, on the target's first window (focused, else first of `AXWindows`):
  1. `AXUIElementSetMessagingTimeout(app, 0.25)` (ADR-0015).
  2. Read `AXEnhancedUserInterface` on the app element. With policy `toggle` and value true, set it false. Restore the prior value in a `defer` on every path (skip when absent or already false).
  3. Write size, then position, then size (ADR-0022). Record each AX return code.
  4. Read the frame back. Delta = readBack - target (x, y, w, h). Classify like FrameWriteResult: applied (delta within 1 pt), clamped (size differs), refused(code), timedOut (`.cannotComplete` after 0.25 s), elementGone.
  5. On timedOut: retry once; a second consecutive timeout aborts the sequence (ADR-0015 C7). Record both timings.
  6. Wall time per Snap in ms (monotonic clock) around steps 2 to 4.
- Output: one JSON line per run (`--json`) and a final markdown table row: app, runs, applied/clamped/refused/timedOut counts, median and max wall ms, max |delta|, Enhanced UI before/after, restored (yes/no).
- Safety: refuse to run without `--target`; never touch windows outside the named app; always restore the original frame at the end of a run set (write the saved frame back).
