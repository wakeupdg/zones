# T61: App icon Dark, Clear and Tinted styles

Kind: design fix (orchestrator, from DG's Dock check after the T57 install, 2026-10-25). Blocked by: none (T57 is merged). Runs in parallel with T59 (see "File split").

## Evidence
- T57 ships `App/AppIcon.icon` (Icon Composer). After a Dock icon-cache reset, the Dock shows the glass icon. Default (light) style: OK.
- DG's Dock check, reported by the t57-finish session:
  - **Dark:** the glow is a hard ellipse. A solid dark color replaces the soft gradient of `Glow.svg` (the glow's blur is a radial gradient inside the SVG; its 40 % opacity is set in `icon.json`).
  - **Clear:** the lit zone is gray. `icon.json` has no Clear or Tinted settings, so the system desaturates it.
  - **Tinted:** not checked.
- Decision context: `docs/design/README.md` "Decision" (Sash x Coal Fern, Glass tiles, Active zone). Figma file c1pMnDAGUn6jiXCu9yQp1I, Section 6 `50:1597` (masters light `50:1607`, dark `50:1618`, layers `50:1634` Background, `50:1639` Glow, `50:1644` Lit zone, `50:1652` Tiles).

## Goal
1. Dark: the glow stays soft (a gradient, not a hard shape). Find why Icon Composer flattens it in Dark (a dark-mode fill override, a layer specialization, or the SVG gradient itself) and fix it in the `.icon`.
2. Clear and Tinted: the lit zone still reads as the "active zone" (DG decides the look). Add Clear/Tinted specializations in `icon.json` as Icon Composer supports them.
3. DG steers each visual choice. Show DG the options before you commit one.
