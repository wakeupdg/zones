- State is guarded by `OSAllocatedUnfairLock<State>` or actor isolation. Never `@unchecked Sendable` (the only one in the repo is `WindowHandle`, AC-161).

Fake contract (CONTRACTS.md line 278): every fake exposes `enqueue(_ response)`, `calls: [Call]` (an enum per seam), `latency: TimeInterval` applied through the injected `FakeClock`, and `reset()`. `FakeClock` exposes `pending: [TimerID]`, `advance(by:)`, `fire(_:)`.

Design decisions this brief fixes (do not re-litigate):
- Each fake: `public final class FakeX: <Seam>, Sendable` (or `actor`/`@MainActor final class` where the seam methods are actor-isolated), `init(clock: FakeClock)`; nested `public enum Call: Hashable, Sendable` with one case per protocol method, carrying its arguments.
- `enqueue(_ response: Response)` pushes a scripted result per method (one `Response` enum per fake, or one queue per method). An empty queue returns a documented neutral default (for example `.ok`, `[]`, `nil`, `.value` of last enqueued) and never traps.
- `latency` default 0. When > 0, a call completes its result only after `clock.advance(by:)` crosses the latency: implement it by scheduling a `Clock` timer (any `TimerID`, for example `.frameSample`) and resolving the pending result when it fires. Synchronous seam methods may instead record `latency` and expose the result through an async helper; whichever you pick, `FakeContractTests` must show that with `latency = 2` nothing resolves at `advance(by: 1)` and it resolves at `advance(by: 1)` again. Keep the one mechanism identical across fakes (a shared small helper in `Fakes/` is fine, but it counts toward the file list: put it inside FakeWindowSystem.swift or a `private` extension, not a new file).
- Stream seams (`notices`, `events`, `signals`, `changes`, `presses`): fake owns an `AsyncStream.Continuation`; `emit(_:)` yields; `reset()` finishes and recreates.
- `FakeFileSystem(failAfterBytes: Int? = nil)`: in-memory `[URL: Data]`. Total bytes written is tracked per `writeAtomic`; when a write would take the cumulative bytes past `failAfterBytes`, it throws `FakeFileSystemError.diskFull`, leaves the previous file content untouched (atomic) and logs the call. `reset()` clears files, counter and calls.
- `ArrayLogSink`: `events: [LogEvent]` (lock-guarded), `write` appends and logs a call; `enqueue` is a no-op-free pass-through that preloads events for tests that read them back (document it in one line).
- `Generator.failureMessage(seed:layout:note:)` returns `"seed=\(seed) layout=\(String(describing: layout)) note=\(note)"`: the seed is the plain decimal `UInt64` (no separators, no hex).
