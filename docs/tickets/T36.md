## Goal
- The running app builds its whole object graph in one place (`CompositionRoot`), called from `AppDelegate.applicationDidFinishLaunching`.
- Production adapters and the `WindowActor` are constructed there; each reducer gets one small driver that only translates events in and effects out.
- Drag path: `EventTapInputSource` events feed `DragSessionReducer`; phase-one verdicts come from `ExclusionPolicy` plus `CGWindowEnumerator` candidates; frame samples are batched on the actor at 60 Hz only while pressed; `requestArmContext` is answered from `TopologyMonitor` and `LayoutStore`; effects go to `PanelOverlayPresenter`, `SnapService`, `RestoreService`, `OriginalFrameRegistry`.
- Around it: `PermissionMachine` interpreter with a `ProductionClock`, `TapRecovery`, `ShortcutStore` with `CarbonHotkeyRegistrar`/`ShortcutDispatcher`/`ShortcutResolver`, `TopologyMonitor` over `ScreenDisplayProvider`, menu rebuilt from `MenuModel` on every open, wake/quit effect sequences from `AppLifecycle`, `Diagnostics` with Copy Diagnostics preview-first, Enhanced UI recovery at launch.
- End to end: Shift-drag snaps a window into a Zone on every Display (three Displays, mixed scale).

## Acceptance
(copied verbatim from docs/LOCKED-SPEC.md; both are manual)

### AC-070 (manual) — Cross-scale Snap on screen
Statement: Snapping a window from a 2x Display into a Zone on a 1x Display lands its edges on the Overlay's rectangle with no visible seam, and across three Displays no other window moves.
Covers: US-050, US-053, US-028
Verify: Zoom a screenshot of the landed window and Overlay edges; count moved windows (0).

### AC-157 (manual) — Idle CPU
Statement: With twenty snapped windows and no interaction for ten minutes, Zones averages under 1 percent CPU in Activity Monitor.
Covers: US-131
Verify: Snap twenty windows; wait ten minutes; read the average.

```swift
// Clock (ZonesCore) -- IMPLEMENT as ProductionClock
public enum TimerID: String, Codable, Sendable { case trustPoll, healthTick, suspectResolve, relaunchGate, deadTapRetry, nilUUIDRetry, topologyDebounce, frameSample, unresponsiveCooldown }
public struct TimerHandle: Hashable, Sendable { public let id: TimerID; public let token: UInt64 }
public protocol Clock: Sendable { var now: TimeInterval { get }   // monotonic seconds
  func schedule(_ id: TimerID, after seconds: TimeInterval, repeats: Bool, _ fire: @Sendable @escaping () -> Void) -> TimerHandle
  func cancel(_ handle: TimerHandle) }

// WindowActor and seams (Windowing)
@globalActor public actor WindowActor { public static let shared: WindowActor }    // ADR-0015: every AX call is @WindowActor; UI is @MainActor
public enum AXNotice: Hashable, Sendable { case destroyed(WindowKey), appTerminated(pid_t), moved(WindowKey), apiDisabled }
public protocol WindowSystem: Sendable {   // Production: AXWindowSystem
  @WindowActor func setTimeouts(perApp: TimeInterval, processWide: TimeInterval)              // at launch (AC-159)
  @WindowActor func element(at point: CGPoint) -> WindowHandle?; @WindowActor func windows(of pid: pid_t) -> [WindowHandle]
  @WindowActor func focusedWindow() -> WindowHandle?
  @WindowActor func frame(_ h: WindowHandle) -> AXRead<CGRect>; @WindowActor func frames(_ hs: [WindowHandle]) -> [WindowKey: AXRead<CGRect>]  // one batched call per tick
  @WindowActor func facts(_ h: WindowHandle) -> AXRead<WindowFacts>
  @WindowActor func trivialRead() -> AXStatus                                                  // heartbeat / recovery probe
  func notices() -> AsyncStream<AXNotice> }   // (setPosition/setSize/enhancedUI omitted: only FrameWriter calls them)
public protocol WindowEnumerator: Sendable {   // Production: CGWindowEnumerator
  func onScreenWindows() -> [WindowRef]; func windows(ids: [WindowID]) -> [WindowRef]
  func candidates(under point: CGPoint, hint: WindowID?) -> [WindowRef] }                       // hint first, then hit test; z-ordered; uncapped
public struct InputEvent: Hashable, Sendable { public var kind: InputKind; public var point: CGPoint; public var flags: ModifierSet; public var windowUnderPointer: WindowID?; public var time: TimeInterval }
public enum TapStart: Hashable, Sendable { case started, unavailable }
public enum TapSignal: Hashable, Sendable { case disabledByTimeout, disabledByUserInput, recreated(Bool) }
public protocol InputSource: Sendable {   // Production: EventTapInputSource
  var config: TapConfig { get }; func start() -> TapStart; func stop(); func reenable() -> Bool; func recreate() -> TapStart
  var events: AsyncStream<InputEvent> { get }; var signals: AsyncStream<TapSignal> { get } }
public protocol DisplayProvider: Sendable {   // Production: ScreenDisplayProvider
  func snapshot() -> TopologySnapshot; var changes: AsyncStream<RawDisplayChange> { get } }
public protocol OverlayPresenter: Sendable {   // Production: App's PanelOverlayPresenter
  @MainActor func show(_ scene: OverlayScene); @MainActor func highlight(_ h: Highlight); @MainActor func hide()
  @MainActor func reassert(); @MainActor func orderOut(); @MainActor func resize(to snapshot: TopologySnapshot) }
public protocol HotkeyRegistrar: Sendable {   // Production: CarbonHotkeyRegistrar
  @MainActor func register(_ chord: Chord, for action: ShortcutAction) -> HotkeyRegistration
  @MainActor func unregister(_ action: ShortcutAction); @MainActor func bound(_ action: ShortcutAction) -> Chord?; var presses: AsyncStream<ShortcutAction> { get } }
public protocol PermissionProbe: Sendable { func isTrusted() -> Bool; @MainActor func openAccessibilitySettings(); var launchedAtLogin: Bool { get } }

// Drag Session reducer (§3.1) -- the driver feeds events, interprets effects
public enum DragEvent: Hashable, Sendable {
  case mouseDown(point: CGPoint, flags: ModifierSet, candidates: [WindowRef], phaseOne: Verdict, config: ModifierConfig)
  case dragged(point: CGPoint, flags: ModifierSet), mouseUp(point: CGPoint, flags: ModifierSet), flagsChanged(ModifierSet)
  case frameSample([WindowID: SampleResult])          // one batched read per tick; facts ride with the first moved sample
  case armContext(ArmContext)                         // the driver answers requestArmContext
  case windowGone, topologyChanged(ArmContext), spaceChanged, wake }
public enum DragEffect: Hashable, Sendable {
  case requestSample([WindowID]), stopSampling, requestArmContext(window: WindowRef, point: CGPoint)
  case showOverlay(OverlayScene), updateHighlight(Highlight), hideOverlay, reassertPanels
  case snap(SnapPlan), restore(WindowRef, downFrame: CGRect), skip(SkipReason, WindowRef?), log(String) }
public enum DragSessionReducer { public static func reduce(_ s: DragState, _ e: DragEvent) -> (DragState, [DragEffect]) }   // pure; no Clock, no actor
```
Guarantees: `hideOverlay` precedes `snap`/`restore` in the mouseUp step (AC-053); `requestSample` only in `pressed`, never after `moving` (AC-156).

## ADRs
- 0006 Drag detection: mouse events drive the gesture, AX frame polling confirms a window move.
- 0015 All AX calls run on a dedicated WindowActor with a 250 ms messaging timeout; UI on MainActor. Amendment 2026-10-24 (C7): a second consecutive timeout against the same app aborts the Snap sequence (one retry), then a short unresponsive cooldown.
- 0018 Besides per-app exclusions, Zones skips windows it cannot or should not move. Amendment (C4): phase one uses CG facts only, before any AX call, and skips own pid and system agents.
- 0021 One onboarding window; poll AXIsProcessTrusted; badge and re-onboard on revocation. Amendment (C5): the 1 s trust poll runs only in notGranted/revoked/needsRelaunch; in granted a single 5 s health tick runs; revocation is derived from apiDisabled or a nil tap.
- 0022 Frame writes go size, position, size; read back; Enhanced UI off during the write. Amendment (C6): restore the value in a defer on every path; drain pending restores on Quit and on revocation; once-per-app recovery record.
- 0007 Snap needs the activation modifier at drop; 0009 Original frame captured at first snap; 0011 Carbon hotkeys; 0014 No re-layout on topology change, nothing in full-screen Spaces; 0019 Menu-bar-only app, no App Sandbox; 0023 One click-through NSPanel per screen (read only if you touch the panel).
