# T14: Exclusion policy, exclusions pane model, production CGWindowEnumerator

Kind: build. Blocked by: T02, T04, T05 (all merged before you start). Estimate: 120000 tokens. Branch: ticket/T14.

## Goal

- `ExclusionPolicy.phaseOne` decides from CoreGraphics facts alone (own pid, system agent bundle, excluded bundle, pid in the unresponsive cooldown via `AppHealth`) and returns `Verdict`. No Accessibility call happens in phase 1.
- `ExclusionPolicy.phaseTwo` decides from AX `WindowFacts` (non-standard subrole, sheet or popover, system dialog, full screen, position not settable). A window whose size is not settable but whose position is returns `allow(.positionOnly)`.
- `ExclusionPolicyTests.table` is a table test with exactly one row per `SkipReason` per phase that the policy produces, plus the allow rows.
- `ExclusionsPaneModel` is keyed by bundle identifier: rows show the identifier beside the name; adding from a running app or from a file URL stores the bundle identifier.
- `CGWindowEnumerator` (production `WindowEnumerator`) reads only windowNumber, pid, bounds and layer (never a name, LI-003), and implements `onScreenWindows`, `windows(ids:)` and `candidates(under:hint:)` (CGEvent window id hint first, then a z-ordered hit test).

CoordinateSpace (CONTRACTS §1.1), which you consume in the enumerator:

public enum CoordinateSpace { public static func appKitRect(_ ax: CGRect, primaryFrame: CGRect) -> CGRect }  // plus axRect, display(for:in:), panelLocal

Seam rule (CONTRACTS lines 20-22): every CGRect and CGPoint crossing a seam is in AppKit global coordinates (origin bottom-left of the primary display). CG window bounds are top-left global, so the enumerator converts each bounds rect with `CoordinateSpace.appKitRect`. `import ApplicationServices` and `CGWindowList*` calls appear only under `Sources/ZonesWindowing/Adapters/` (AC-162).

### Design decisions this brief fixes (not in CONTRACTS; follow them)

- Phase 1 order: ownProcess (`ref.pid == ownPid`), systemAgent (`ref.bundleID` in `systemAgents`), excludedBundle (`ref.bundleID` in `exclusions`), unresponsive (`health.isUnresponsive(ref.pid, now:)`), else `allow(.full)`. A nil `bundleID` can match neither systemAgent nor excludedBundle. Phase 1 never returns ambiguousMatch (candidate resolution produces that elsewhere).
- Phase 2 order: subrole `sheet` or `popover` -> sheetOrPopover; `systemDialog` or `systemFloatingWindow` -> systemDialog; `dialog`, `floating`, `unknown` -> nonStandardSubrole; `isFullScreen` -> fullScreen; `!positionSettable` -> positionNotSettable; `!sizeSettable` -> `allow(.positionOnly)`; else `allow(.full)`.
- `ExclusionsPaneModel.rows` returns one Row per bundle id; `name` = `names[bundleID]` or the bundle id itself when absent; sorted by name (case-insensitive), then bundle id.
- Additive helpers on `ExclusionsPaneModel` (Foundation only, no AppKit): `static func bundleID(forAppAt url: URL) -> String?` (via `Bundle(url:)?.bundleIdentifier`) and `static func add(appAt url: URL, to: inout Set<String>) -> Bool` (false when the URL has no bundle identifier; nothing stored). Add-from-running-app uses the existing `add(bundleID:to:)`; the App layer supplies the running app's bundle id.
- `CGWindowEnumerator` is a `struct` conforming to `WindowEnumerator`, stateless, `Sendable`. `init(primaryFrame: @escaping @Sendable () -> CGRect)` (production passes the primary screen frame; tests pass a constant). `bundleID` on each ref comes from `NSRunningApplication(processIdentifier:)?.bundleIdentifier`, cached per pid within one call. Never read `kCGWindowName`, `kCGWindowOwnerName`, alpha or `IsOnscreen`; read only `kCGWindowNumber`, `kCGWindowOwnerPID`, `kCGWindowBounds`, `kCGWindowLayer`.
- `onScreenWindows`: `CGWindowListCopyWindowInfo([.optionOnScreenOnly, .excludeDesktopElements], kCGNullWindowID)`, keep layer 0, preserve CG order (front to back). A nil result (no GUI session) returns `[]`.
- `windows(ids:)`: `CGWindowListCreateDescriptionFromArray` with the ids; match by `kCGWindowNumber`, never by array index (vanished ids are dropped silently); keep layer 0; return in the order of `ids`.
- `candidates(under:hint:)`: `point` is AppKit-global. First `hint` (resolved via `windows(ids: [hint])`, included even if the point misses its frame, because the event field is authoritative); then every layer-0 on-screen window whose AppKit frame contains `point`, front to back, hint not repeated; uncapped.
- Put the logic in pure internal functions so tests need no window server: `static func refs(from infos: [[String: Any]], primaryFrame: CGRect, bundleID: (pid_t) -> String?) -> [WindowRef]` and `static func hitTest(_ refs: [WindowRef], at point: CGPoint, hint: WindowID?, hinted: [WindowRef]) -> [WindowRef]`. The CG calls stay in thin wrappers.

## Test plan

Swift Testing (`import Testing`), one red-green slice per commit, in this order.

1. `ExclusionPolicyTests.table`, phase-one half (AC-143; exercises `ExclusionPolicy.phaseOne`, `Verdict`, `AppHealth`). A table of `(name, ref, ownPid, exclusions, health, now, expected)` with exactly one row for each of ownProcess, systemAgent, excludedBundle, unresponsive, plus an allow(.full) row. The systemAgent reason additionally runs over all six `systemAgents` ids. unresponsive uses `var h = AppHealth(); h.markUnresponsive(pid, now:)` (check the real initializer). Assert each reason appears in exactly one row.
2. `ExclusionPolicyTests.table`, phase-two half (exercises `phaseTwo`, `WindowFacts`, `Subrole`). One row each for nonStandardSubrole, sheetOrPopover, systemDialog, fullScreen, positionNotSettable; sheetOrPopover is checked with both `.sheet` and `.popover`, systemDialog with both `.systemDialog` and `.systemFloatingWindow`. Row `sizeSettable == false` with position settable -> `allow(.positionOnly)`. Row standard/settable -> `allow(.full)`. Final assertion inside `table`: the set of skip reasons in the rows equals `Set(SkipReason.allCases)` minus `ambiguousMatch`, with each reason in exactly one row (so a future reason fails the test).
3. `ExclusionPolicyTests.precedence` (exercises ordering): own pid beats systemAgent beats excluded beats unresponsive; fullScreen beats positionNotSettable; nil bundleID skips neither systemAgent nor excludedBundle; a phase-one allow does not depend on `WindowFacts`.
4. `ExclusionsPaneModelTests.bundleIdentifierKeyed` (AC-142; exercises `rows`, `add`, `Row`). Exclusions are `Set<String>` of bundle ids: `add` stores the id, adding the same id twice leaves one element; `rows` has one `Row` per id carrying `bundleID` next to `name`; two apps with the same display name but different ids give two rows; a missing name falls back to the id; order is name then id.
5. `ExclusionsPaneModelTests.addFromFileURL`: build a temporary `.app` bundle (Contents/Info.plist with CFBundleIdentifier) under `FileManager.default.temporaryDirectory`, assert `add(appAt:to:)` stores that identifier and returns true; a plain directory returns false and leaves the set unchanged. Add the running-app path as a one-line test: `add(bundleID: "com.apple.calculator", to:)` stores the bundle id, not the name.
6. `CGWindowEnumeratorTests.parseKeepsLayerZeroAndNoNames` (exercises `refs(from:)`, `WindowRef`, `CoordinateSpace`): feed dictionaries carrying kCGWindowNumber, OwnerPID, Bounds (as CFDictionary of CGRect), Layer, plus decoy `kCGWindowName` and `kCGWindowOwnerName` values. Assert layer != 0 entries are dropped, order is preserved, frames are converted to AppKit coordinates against a fixed `primaryFrame`, the `bundleID` closure is used, and the output type carries no name anywhere (the struct has no such field; assert the decoys do not appear in `String(describing:)` of the result).
7. `CGWindowEnumeratorTests.hitTestOrder` (exercises `hitTest`, `candidates` semantics): hint first even when the point misses it; then containing windows front to back; no duplicate of the hint; uncapped (50 stacked windows all returned); point outside every window and no hint gives `[]`; hint absent from the list is ignored.
8. Wire-up: `CGWindowEnumerator` conforms to `WindowEnumerator` and the thin CG wrappers call the pure helpers. No automated test touches the live window server. Compile check only: `let _: any WindowEnumerator = CGWindowEnumerator(primaryFrame: { .zero })` inside a test that does not call it.
