# T06: Spike: AX revocation signal, moved-notification cadence, AXObserver thread (SPK-006, SPK-007, SPK-013)

Kind: spike. Blocked by: T01 (root Package.swift exists). Est: 90k tokens. Protocol: none. Fake: none. Tests: manual run log in docs/spikes/SPK-006.md.

## Goal

- Build `Spikes/AXSignalsProbe`, a standalone SPM executable (not part of the root package) with three modes: `revoke`, `cadence`, `thread`.
- `revoke` records whether a trivial AX read of the system-wide element returns apiDisabled within 5 s of revoking a running process, what `AXIsProcessTrusted` reads afterwards, and whether an already-created listen-only tap keeps delivering events.
- `cadence` logs kAXWindowMovedNotification / kAXWindowResizedNotification timing against mouse down/up during a live drag in Finder, Safari and Chrome.
- `thread` adds an AXObserver run-loop source on a dedicated thread and confirms callbacks arrive on that thread, still arriving after 60 s idle.
- Verdicts land in `docs/spikes/SPK-006.md`, `SPK-007.md`, `SPK-013.md`. SPK-006 decides `PermissionConfig.heartbeatEnabled` (true only if the signal is proven). The verdicts fix the expectations of AC-007, AC-009, AC-093, AC-156, AC-158 and unblock T13 (observer adapter) and T20 (heartbeat flag).
- No shipped Zones code changes. No automated tests; evidence is run logs.

## Interface contracts

This ticket IMPLEMENTS none of them in shipped code and edits no contract. The probe keeps private local copies of the shapes so T13 and T20 can lift the code. It CONSUMES (as design reference, from docs/CONTRACTS.md 3.0 and 3.5):

```swift
public enum AXStatus: Hashable, Sendable { case ok, timedOut, elementGone, apiDisabled, refused(Int32) }
public enum AXNotice: Hashable, Sendable { case destroyed(WindowKey), appTerminated(pid_t), moved(WindowKey), apiDisabled }
public protocol WindowSystem: Sendable {   // Accessibility. Production: AXWindowSystem. Fake: FakeWindowSystem
  @WindowActor func trivialRead() -> AXStatus                                                  // heartbeat / recovery probe
  func notices() -> AsyncStream<AXNotice> }
public struct PermissionConfig: Hashable, Sendable { public var launchedAtLogin: Bool; public var heartbeatEnabled: Bool /* SPK-006 */; public var reducerIdle: Bool }
```

- WindowSystem.trivialRead: SPK-006 proves whether it can return `.apiDisabled` on a revoked running process. Probe's trivial read = `AXUIElementCopyAttributeValue(AXUIElementCreateSystemWide(), kAXFocusedApplicationAttribute, &v)`; log the raw `AXError` rawValue next to the mapped name (apiDisabled is -25211).
- WindowSystem.notices / AXNotice: SPK-007 and SPK-013 decide how T13 feeds `.moved`, `.destroyed`, `.appTerminated` (bookkeeping only) from an observer thread into the stream.
- PermissionConfig.heartbeatEnabled: the SPK-006 verdict is the default value T20 ships.

## ADRs

- ADR-0021 One onboarding window; poll AXIsProcessTrusted; badge and re-onboard on revocation. Amendment 2026-10-24 (C5): trust poll cannot detect revocation of a running process; revocation is derived from runtime signals (apiDisabled, nil tap); a heartbeat (trivial AX read in the 5 s health tick) is enabled only if SPK-006 proves macOS delivers the signal.
- ADR-0015 All AX calls run on a dedicated WindowActor with a 250 ms messaging timeout; UI on MainActor. Amendment 2026-10-24 (C7): second consecutive timeout aborts the Snap sequence. Probe calls set `AXUIElementSetMessagingTimeout` to 0.25 s.
- ADR-0006 Drag detection: mouse events drive the gesture, AX frame polling confirms a move; `kAXWindowMovedNotification` fires only at gesture end, so it is bookkeeping only. SPK-007 confirms or refutes this.
- ADR-0020 Accessibility is the only TCC permission (listen-only tap needs only AX). The probe's tap must be listen-only.

Probe CLI (all output is JSON lines, one object per event, with `t` = seconds since start from `ProcessInfo.processInfo.systemUptime`, and is also appended to `docs/spikes/logs/<mode>-<app>-<run>.jsonl`; create that dir):

- `AXSignalsProbe` with no args: print usage, exit 64.
- `AXSignalsProbe selftest`: no permission needed; checks the AXError-to-name mapping table and the interval-statistics helper; exit 0 on pass.
- `AXSignalsProbe revoke [--seconds 90]`:
  - Print `AXIsProcessTrusted()` and the responsible process note (run from Terminal means Terminal's grant is what is tested).
  - Create a listen-only tap (`.listenOnly`, session tap) for mouseMoved, leftMouseDragged and flagsChanged on the main run loop.
  - Every 250 ms log: trivial read result (raw rawValue plus name), `AXIsProcessTrusted()`, `CGEvent.tapIsEnabled`, and tap events counted in that interval.
  - Pressing Return on stdin logs `{"marker":"revoked-now"}`; the human presses it at the instant of flipping the toggle off.
  - Summary: first apiDisabled latency from the marker (pass for heartbeat if at most 5.0 s), the trusted value read over the 10 s after the marker, tap events delivered after the marker (human keeps moving the mouse), tap enabled flag after.
- `AXSignalsProbe cadence --app finder|safari|chrome [--seconds 40]`:
  - Bundle ids: com.apple.finder, com.apple.Safari, com.google.Chrome. Register moved and resized on the front window and on the application element; log which element delivered each notification.
  - A listen-only tap logs leftMouseDown / leftMouseUp as `down` / `up` markers.
  - The observer source lives on the dedicated thread helper shared with `thread` mode.
  - Summary: per notification kind, count, count between down and up, count within 50 ms after up, min / median / max inter-arrival ms, verdict line `end-of-gesture-only` or `continuous`.
- `AXSignalsProbe thread [--idle 60] [--target calculator]`:
  - Part A (no permission needed): a custom `CFRunLoopSource` on a dedicated `Thread` named `ax-observer`, no keepalive timer, signalled from main at t=0 and again after `--idle` seconds; assert the callback ran on that thread (`pthread_equal` against the thread's own `pthread_self` captured at start) and never on main; log whether `CFRunLoopRun` returned early.
  - Part B (needs AX trust; if `AXIsProcessTrusted()` is false print `SKIP not trusted`, exit 3): an `AXObserver` for Calculator's pid (/System/Applications/Calculator.app, launch it with `open -a Calculator`); `AXObserverGetRunLoopSource` added to that same thread's run loop in `.defaultMode` before `CFRunLoopRun`. Nudge the Calculator window by 10 px and back at t=0 and after `--idle` seconds; assert both callbacks ran on `ax-observer`, record latency from nudge to callback.

## Test plan

Slice convention for a spike: "red" = a check command that fails before the slice, "green" = it passes after. There are no XCTest targets and no property tests (no AC here asks for them). Each slice is one commit.

1. Skeleton. Red: `swift build --package-path Spikes/AXSignalsProbe` finds no package. Green: it builds; running with no args prints usage and exits 64. Contract: none.
2. Core helpers and `selftest`. Green: `swift run --package-path Spikes/AXSignalsProbe AXSignalsProbe selftest` exits 0. Asserts: AXError rawValue -25211 maps to `apiDisabled`, 0 to `ok`, -25202 (invalidUIElement) to `elementGone`, anything else to `refused(raw)`; the interval-stats helper returns min/median/max for a fixed list. Exercises: AXStatus shape.
3. `thread` Part A. Green: `... thread --idle 2` exits 0 with callbacks on `ax-observer` at t=0 and t=2. Exercises: ADR-0015 thread model, WindowSystem.notices source side.
4. `thread` Part B. Green: with Accessibility granted to the host terminal, `... thread --idle 60` exits 0 and both Calculator callbacks arrive on `ax-observer`. Not trusted: SKIP exit 3 is acceptable for the commit; the 60 s run goes in the human-run list. Writes docs/spikes/SPK-013.md.
5. `cadence`. Green: `... cadence --app finder --seconds 5` runs without a drag and prints a summary with zero counts and no crash (needs trust, else SKIP exit 3). Writes the cadence table into docs/spikes/SPK-007.md once logs exist.
6. `revoke`. Green: `... revoke --seconds 3` prints trusted state, tap status and 250 ms rows without crashing (a tap that cannot be created logs `tapNil` and continues). Writes docs/spikes/SPK-006.md.
7. Verdict docs filled from logs (see Verdict format). AC-009 is manual and needs only the `revoke` implementation plus the recorded probe value; AC-007, AC-093, AC-156, AC-158 are covered by tests in T13 and T20, not here.
