# T29: Shell models: menu, status item, General status rows, login-launch path, quit sequence

Kind: build. Blocked by: T20 (PermissionMachine), T17 (LayoutStore), T11 (Diagnostics/Log). Estimate: 130k tokens. Branch: ticket/T29. Module: ZonesWindowing only (Shell/), pure value logic, no AppKit, no App/ changes. Protocol: none. Fake consumed (not edited): FakeWindowSystem (ZonesTestSupport).

## Goal

- `MenuModel.build` returns `[MenuItem]` in the AC-016 order: disabled header "<Display> — <Layout>", radio group of Templates (named with counts) then custom Layouts with the active one checked, checkable "Exclude <App>", Edit Layouts, Settings, "Grant Accessibility" only when not granted, About, Quit.
- `MenuModel.build` is a plain synchronous pure function: it never touches the WindowActor or any WindowSystem (AC-017), proven against a never-returning FakeWindowSystem.
- `StatusItemModel.derive` implements the badge table (unbadged only when granted and tap alive) and always sets the template-image flag.
- `GeneralPaneModel.statusRows` returns exactly two rows: Accessibility and Event tap.
- `AppLifecycle.quitEffects()` returns disableTap, invalidateTap, orderPanelsOut, drainEnhancedUI, removeRecoveryRecord in that order; `wakeEffects()` returns revalidateTap, probe, forceTopologySnapshot, orderPanelsOut (AC-024 wording).
- `AppLaunchTests.loginLaunchShowsNoWindow` drives the real `PermissionMachine.reduce` with `PermissionConfig.launchedAtLogin = true` and proves no window effect, only badge plus grant menu item when not granted.

## Design decisions (settled; follow them)

- Header text: `"\(display.name) — \(layoutName)"` with an em dash and single spaces. `layoutName` is the title of the assigned Layout (below); if `store.layout(assignment)` is nil use `assignment.rawValue`. If `cursorDisplay` is nil the header is `"No display"` and the layout group is still built with nothing checked.
- Layout titles: built-in (`layout.builtIn != nil`) title is `"\(ref.template.rawValue) \(ref.count)"` (for example "Columns 3", "Priority Grid 3"); custom title is `layout.name`. Order: `store.builtIns` in store order, then `store.custom` in store order. `checked` is `layout.id == assignment`. Exactly zero or one checked.
- `excludeApp` is present only when `frontmost != nil`; `checked = exclusions.contains(bundleID)`. Title shown by the UI is "Exclude <name>"; the model carries `name` and `bundleID` only.
- `grantAccessibility` is present for notGranted, revoked, needsRelaunch; absent for granted and suspect (suspect is still trusted until proven otherwise). Mirror what T20's reducer emits as `grantMenuItem(Bool)` for the same states; if it disagrees with this rule, follow the reducer and note it in the ledger.
- Separators: one `.separator` between groups: after the header, after the layout group, after the exclude item (when present), after Grant/Settings group, before `quit`'s group. Tests assert the order after removing separators, plus one test that no two separators are adjacent and the list neither starts nor ends with one. The header is the only disabled item (the UI layer disables it; the model has no flag).
- Badge table: `badged = !(p == .granted && tap == .alive)`. So badged for notGranted, suspect, revoked, needsRelaunch, and for tap dead or unavailable. `isTemplate` is always true.
- General rows: `[("Accessibility", granted ? "Granted" : "Not granted"), ("Event tap", tap == .alive ? "Alive" : "Dead")]`. Accessibility is "Granted" for `.granted` and `.suspect`, "Not granted" otherwise. `.unavailable` shows "Dead". Always exactly two rows in this order.
- Wake effects order: `[.revalidateTap, .probe, .forceTopologySnapshot, .orderPanelsOut]`.
- Window effects for AC-012 are `showOnboarding`, `dismissOnboarding`, `offerRelaunch`. Housekeeping effects (`schedule`, `cancel`, `probe`, `heartbeat`, `startTap`, `registerWindowHotkeys`, `unregisterWindowHotkeys`) are allowed.

8. `MenuModelTests.nilDisplayAndMissingLayout`: nil `cursorDisplay` gives header "No display" and no layout checked; unknown assignment id gives header using the raw id and no crash.
