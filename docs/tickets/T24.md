# T24: Original Frame registry and Restore service

Kind: build. Blocked by: T15 (FrameWriting, FrameWriter, SnapOutcome, AppHealth; T02 fakes). Estimate: 130000 tokens. Branch: ticket/T24. Module: ZonesWindowing only (new folder Sources/ZonesWindowing/Restore/). No AppKit, no App/ changes.

## Goal

- `OriginalFrameRegistry` is a pure value type keyed by `WindowKey`. It captures an Original Frame exactly once per window: on the mouse path the mouse-down frame of the resolved window (`SnapPlan.originalFrame`), on the keyboard path the pre-write read-back frame. A later capture never overwrites (returns false).
- It also stores the last applied Snap read-back frame per window (`LastSnapRecord`). A Span Snap and a single-Zone Snap record the same entry kind, so Restore returns the same Original Frame for both.
- Forget rules: a successful Restore (`applied` or `clamped`) forgets the entry, so Snap, Restore, hand-move, Snap, Restore returns the hand-placed frame. `AXNotice.destroyed` forgets that key; `appTerminated(pid)` evicts every entry of that pid; `elementGone` from a write evicts at the next touch; there is no periodic sweep and no timer.
- `RestorePlanner.plan` returns the target frame. If the Original Frame intersects no Display it is clamped into the visible frame of the Display the window currently overlaps most (`CoordinateSpace.display(for:in:)`). A full-screen window yields `noOp(.fullScreen)`.
- `RestoreService.restore` writes through `FrameWriting` (size, position, size, read back), maps the result to `RestoreResult`, and removes the entry on applied or clamped. No entry or full-screen: `noOp(reason)`, exactly one log line (category `.restore`, no title), and no write.

## Interface contracts

Source: docs/CONTRACTS.md. Section 3.3 is the shape to implement. Do not change a signature; any additive helper goes in the ledger.

IMPLEMENTS: `OriginalFrameRegistry`, `RestoreResult`, `RestorePlanner`, `RestoreService`.
CONSUMES (declared elsewhere, do not redefine): `OriginalFrameEntry`, `LastSnapRecord`, `CapturePath`, `WindowKey`, `FrameWriting`, `FrameWriteResult`, `NoOpReason`, `AXNotice`, `CoordinateSpace.display`, `TopologySnapshot`, `WindowFacts`, `WindowRef`, `WindowHandle`, `SnapMode`, `EnhancedUIPolicy`, `AppHealth`, `Clock`, `Log`.

```swift
// §1.4 (CONSUMED; in ZonesCore)
public struct WindowKey: Hashable, Sendable { public var pid: pid_t; public var elementHash: Int }   // registry key (CFHash of the element)
public enum CapturePath: String, Codable, Sendable { case mouse, keyboard }; public struct OriginalFrameEntry: Hashable, Sendable { public var key: WindowKey; public var frame: CGRect; public var via: CapturePath }
public struct LastSnapRecord: Hashable, Sendable { public var key: WindowKey; public var display: DisplayKey; public var zones: Set<Int>; public var frame: CGRect }
// §1.1 (CONSUMED)
public enum CoordinateSpace {
  public static func display(for rect: CGRect, in snapshot: TopologySnapshot) -> DisplaySnapshot?  // max intersection area
}
// §1.3 (CONSUMED)
public enum DisplayKey: Hashable, Sendable { case uuid(String), unstable(String) }     // unstable: session only, never encoded
public struct PersistentDisplayKey: Hashable, Codable, Sendable { public let uuid: String }  // decoder rejects non-UUID (AC-123)
public struct DisplaySnapshot: Hashable, Sendable { public var key: DisplayKey; public var frame: CGRect; public var visibleFrame: CGRect; public var scale: Double
  public var isMain: Bool; public var mirrorOf: DisplayKey?; public var name: String; public var resolution: CGSize }
public struct TopologySnapshot: Hashable, Sendable { public var displays: [DisplaySnapshot]; public var separateSpaces: Bool; public var primaryFrame: CGRect
  public func display(_ key: DisplayKey) -> DisplaySnapshot? }
public enum NoOpReason: String, Codable, Sendable { case sameFrame, zoneAbsent, noEntry, fullScreen, excluded, positionNotSettable, windowAbsent, notIdle }
public enum FrameWriteResult: Hashable, Sendable { case applied(CGRect), clamped(CGRect), refused(Int32), timedOut, elementGone, noOp(NoOpReason) }
public enum SnapMode: String, Codable, Sendable { case full, positionOnly }
// §3.0 (CONSUMED)
public enum AXNotice: Hashable, Sendable { case destroyed(WindowKey), appTerminated(pid_t), moved(WindowKey), apiDisabled }
// §3.2 (CONSUMED; delivered by T15)
public protocol FrameWriting: Sendable {   // size, position, size, read back; Enhanced UI off/on with defer; retry once then abort
  @WindowActor func write(_ target: CGRect, mode: SnapMode, to h: WindowHandle, policy: EnhancedUIPolicy, health: inout AppHealth, now: TimeInterval) -> FrameWriteResult }
// §3.3 (IMPLEMENTED)
public struct OriginalFrameRegistry: Hashable, Sendable {
  public mutating func capture(_ e: OriginalFrameEntry) -> Bool          // false if an entry exists (never overwrites)
  public mutating func recordSnap(_ r: LastSnapRecord); public func entry(_ k: WindowKey) -> OriginalFrameEntry?; public func lastSnap(_ k: WindowKey) -> LastSnapRecord?
  public mutating func forget(_ k: WindowKey); public mutating func evict(pid: pid_t); public mutating func apply(_ n: AXNotice)
}
public enum RestoreResult: Hashable, Sendable { case applied(CGRect), clamped(CGRect), noOp(NoOpReason), failed(FrameWriteResult) }
public enum RestorePlanner { public static func plan(_ e: OriginalFrameEntry, window: WindowRef, facts: WindowFacts?, topology: TopologySnapshot) -> Result<CGRect, NoOpReason> }  // off-display clamp (AC-095)
public struct RestoreService: Sendable { public init(writer: any FrameWriting, clock: any Clock)
  @WindowActor public func restore(_ e: OriginalFrameEntry, handle: WindowHandle, target: CGRect, mode: SnapMode, health: inout AppHealth) -> RestoreResult }
```

Design decisions already made (do not reopen):
- `restore(_:handle:target:mode:health:)` takes a non-optional entry and a precomputed target. The no-entry and full-screen no-ops therefore live one level up. Add ONE additive helper on `RestoreService`, e.g. `restoreFocused(registry: inout OriginalFrameRegistry, key: WindowKey, window: WindowRef, facts: WindowFacts?, handle: WindowHandle, topology: TopologySnapshot, mode: SnapMode, health: inout AppHealth) -> RestoreResult`. It looks up the entry (`noOp(.noEntry)`), calls `RestorePlanner.plan` (`noOp(.fullScreen)`), calls `restore`, and forgets the key on applied or clamped. Note the helper in the ledger.
- The one log line is `Log.shared.event(LogEvent(... category: .restore, level: .info ...))` with no title, pid and bundleID only. Inject nothing new; tests read the line with `ArrayLogSink`.
- `FrameWriteResult` maps to `RestoreResult`: applied to applied, clamped to clamped, noOp(r) to noOp(r), anything else to `failed(result)`. On `failed(.elementGone)` the helper forgets the key (eviction at next touch). Other failures keep the entry.
- `.moved` and `.apiDisabled` notices are bookkeeping and change nothing (ADR-0006).
- The registry holds no Clock, no Task and no timer. `RestoreService` takes a Clock only for `now`.

## ADRs

- ADR-0009 Original frame is captured at first snap, restored by shortcut or by a modifier-drag that ends over no zone. Amendment 2026-10-24 (C2): forget on window close, app quit and successful Restore; capture points are mouse-down frame (mouse) and pre-write read-back (keyboard); later Snaps never overwrite; Span records the same entry kind; off-display Original Frame is clamped into the visible frame of the Display the window overlaps most.
- ADR-0014 No re-layout on display topology change; nothing happens in full-screen Spaces. A full-screen focused window means Restore does nothing (noOp fullScreen, one log line).
- ADR-0015 All AX calls run on a dedicated WindowActor. Amendment 2026-10-24 (C7): second consecutive timeout aborts the sequence, app enters cooldown. `restore` is `@WindowActor`; the registry is a plain value type.
- ADR-0022 Frame writes go size, position, size; read back. Amendment 2026-10-24 (C6): Enhanced UI restored in a defer. T15 owns this; Restore reuses `FrameWriting` and must not reimplement it.
- ADR-0006 Drag detection: `kAXWindowMovedNotification` fires only at gesture end, so `.moved` stays bookkeeping-only.

## Test plan

One red-green slice per commit, in this order. Swift Testing or XCTest as the repo already uses; follow the write-swift skill.
1. `OriginalFrameRegistryTests.firstSnapCapturesPerPath` (AC-089; registry). Capture a mouse entry (frame A, via .mouse) for window W1: returns true. Second capture with frame B returns false and `entry` still A. A keyboard-path entry for W2 stores its pre-write read-back with via .keyboard. `recordSnap` stores the last-Snap frame without touching the entry.
2. `RestoreTests.writesAndRemovesEntry` (AC-090; RestoreService, FrameWriting). With `FakeWindowSystem` and a real `FrameWriter`, restore writes the entry frame (size, position, size order) and returns `applied(frame)`. After `restoreFocused` the registry has no entry. A `clamped` write result also removes it. A `refused` or `timedOut` result returns `failed` and keeps the entry.
3. `RestoreTests.noOpReasons` (AC-092; RestorePlanner, RestoreService). Full-screen facts gives `noOp(.fullScreen)`; empty registry gives `noOp(.noEntry)`. Each case: zero writes on the fake, exactly one `.restore` log line, entry (if any) kept.
4. `RestoreTests.spanAndSnapShareMemory` (AC-094; registry, RestoreService). A single-Zone Snap and a Span Snap (`LastSnapRecord.zones` with 1 vs 2+ members) on two windows with the same pre-Snap frame both leave an `OriginalFrameEntry` of equal shape; Restore returns the same frame for both.
5. `RestoreTests.clampsOntoOccupiedDisplay` (AC-095; RestorePlanner, `CoordinateSpace.display`). Two-Display `TopologySnapshot`; an Original Frame on a now-disconnected Display position, window currently on Display 2: `plan` returns a rect inside Display 2's `visibleFrame`, and the service reports `clamped`. Also assert an in-bounds Original Frame is returned unchanged, and a frame straddling two Displays is not clamped.
6. `OriginalFrameRegistryTests.forgetRules` (AC-093; registry, AXNotice, RestoreService). (a) Snap, Restore, hand-move, Snap, Restore returns the hand-placed frame (second capture succeeds only after the first Restore forgot). (b) `apply(.destroyed(k))` forgets k only. (c) `apply(.appTerminated(pid))` evicts every entry and last-Snap of that pid and none of another pid. (d) `.moved` and `.apiDisabled` change nothing. (e) A write returning `elementGone` forgets the key at next touch. (f) No periodic sweep: after all operations `FakeClock.pending` is empty.
7. Property test (in-house, ADR-0016) in `RestoreTests`: for random Display layouts and random Original Frames, `plan` always yields a rect that lies inside some Display's visible frame or equals the entry frame unchanged when it already intersects a Display. Skip if the repo's property helper is missing; note it in the ledger.

AC-096 is manual: no test. Implement the behavior and note in the ledger that AC-096 awaits a human check.
