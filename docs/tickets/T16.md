# T16: Drag Session reducer core: press, sample, arm, cancel, highlight, snap trigger

Kind: build. Blocked by: T12 (merged before you start). Estimate: 150000 tokens. Branch: ticket/T16.
Protocol: none (pure reducer). Fake: none. Tests: DragSessionReducerTests, ModifierMaskTests.

## Goal

- `DragSessionReducer.reduce` is a pure function over idle, pressed, moving and armed. A click requests no sample; polling starts at the first dragged event and ends at the first moved sample; a size delta over 1 pt (any edge or corner) ends the session; a pause keeps the press.
- The Activation Modifier arms the session whether it was down before the press or pressed after the move. `showOverlay` is emitted only on entry to armed, after `requestArmContext` is answered by `armContext`.
- In armed the highlight follows the cursor Zone, not the window center. Releasing the modifier hides the overlay and cancels. Mouse-up snaps only if its own flags contain the Activation Modifier, and `hideOverlay` precedes `snap`. `windowGone` hides.
- Background windows arm identically (no focus flag exists in the input). `ModifierSet.masked` ignores Caps Lock, Fn and keypad bits. `ModifierConfig` is read at mouseDown only.
- Candidate resolution, phase-one/two skips, cross-Display and Span branches stay as marked extension points for T21 and T22. One file, one switch per state.

Raw CGEventFlags bits for `masked` (do not import AppKit in ZonesCore; use literals, named): shift 1<<17, control 1<<18, option 1<<19, command 1<<20. Ignored: Caps Lock 1<<16, keypad 1<<21, Fn 1<<23, and everything else.

### Reducer behaviour (decided here; follow exactly)

Coordinates are whatever the seam hands in; no conversion. Activation test is `state.config.activation` (never live preferences). `dragged.flags` is ignored; only `flagsChanged` and `mouseUp.flags` carry modifier truth. `EXT` = leave a `// EXTENSION(T21|T22): ...` comment and the stated simple behaviour.

- idle, `mouseDown`: `phaseOne == .skip(r)` gives idle and `[.skip(r, candidates.first)]`; empty candidates gives idle and `[]`; else `pressed` (first `Constants.candidateCap` candidates, `down`, `downFrames` from each ref's frame, flags, config, `samples: 0`, `retried: false`) and `[]`. `.allow(mode)` is accepted and mode is not stored (EXT T21: SnapPlan mode `.full` for now). Any other event in idle: unchanged, `[]`.
- pressed, `mouseDown`: ignored. `dragged`: if `samples == 0` then `samples = 1` and `[requestSample(ids)]`, else unchanged `[]` (`samples` counts requestSample effects issued; this is the "polling started" marker). `flagsChanged(f)`: store `flags = f`, `[]`. `mouseUp` and `windowGone`: idle, `samples > 0 ? [stopSampling] : []`.
- pressed, `frameSample`: walk candidates in z-order; for a `.frame(r, _)` result compare with `downFrames[id]`. Width or height differing by more than `Constants.frameTolerance` is a resize: idle, `[stopSampling]` (checked before origin, so a top-left resize that also moves the origin is a resize). Else origin differing by more than the tolerance is the move: `moving(window: ref, downFrame, flags, config)` and `[stopSampling]` plus `requestArmContext(window: ref, point: down)` only if the activation modifier is in `flags`. No decisive candidate: `samples += 1`, `[requestSample(ids)]`. `.timedOut` and `.gone` count as unmoved (EXT T21: retry, cooldown, ambiguity, phase-two skip from facts, candidates beyond the first decisive one).
- moving: never emits `requestSample`. `dragged`: unchanged `[]`. `flagsChanged(f)`: store flags; if the activation modifier is newly present, `[requestArmContext(window, point: downFrame.origin)]`, else `[]`. `armContext(ctx)`: if activation is in the stored flags then `armed(..., context: ctx, display: nil, hit: .none, span: SpanState(zones: [], display: nil, frozen: false, suspended: false))` and `[showOverlay(OverlayScene(layouts: ctx.topology.displays.compactMap { ctx.layouts[$0.key] }, appearance:, options:))]`; else unchanged `[]`. `mouseUp` and `windowGone`: idle, `[]`.
- armed, `dragged(p)`: `display = HitTest.display(at: p, in: topology)`; `hit` = `HitTest.hit` in that display's layout, else `.none`. If `(display, hit)` changed, store them and emit `updateHighlight(Highlight(display:, primary: {n} for .zone(n)/.nearest(n) else [], secondary: [], dimAll: false))`; else `[]`. EXT T22: `.none` dim and Original Frame, Span modifier, cross-Display suspend.
- armed, `flagsChanged(f)`: activation absent gives `moving(window, downFrame, flags: f, config)` and `[hideOverlay]` (the Span is dropped); present gives stored flags and `[]`. `windowGone`: idle, `[hideOverlay]`. `mouseDown`, `armContext`: ignored.
- armed, `mouseUp(p, flags)`: idle; effects start with `hideOverlay`. If activation is in `flags` (the mouse-up flags, not stored flags) and a hit computed fresh from `p` is `.zone(n)` or `.nearest(n)`, append `snap(SnapPlan(window:, display:, zones: [n], target: Span.rect([n], in: layout), mode: .full, via: .mouse, originalFrame: context.hasOriginalFrame ? nil : downFrame))`. Otherwise only `[hideOverlay]`. "Emits nothing" in AC-036 means no snap and no restore; the overlay is on screen in armed, so it is still hidden. No `restore` effect in this ticket (EXT T22, AC-091).
- Every state, `topologyChanged`, `spaceChanged`, `wake`: unchanged `[]` (EXT T22).
- Known gap: no state holds a live cursor point outside armed. The driver (a later ticket) re-sends its last `dragged` right after `armContext`, which sets the first highlight; mouse-up always recomputes from its own point, so a drop never uses a stale hit. Put this in a doc comment on `reduce` and write a ledger line `CONTRACT-NOTE: armed entry has hit .none until the replayed dragged`. The `DragFixtures` harness below does the replay.
