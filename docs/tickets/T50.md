Kind: fix (QA round 2). Blocked by T31, T36 (all done). Estimate 50k tokens. Protocol: PanelOverlayPresenter (edit). Fake: none needed (AppKit view tests).

## Goal

- `PanelOverlayPresenter.resize(to:)` (or a launch warm-up while panels are ordered out) builds every fill and label layer, so the first `show(scene)` only sets opacity, contents and order.
- The first show + `CATransaction.flush()` on a 3-Display snapshot takes under 8.33 ms in a Debug test build on this Mac (QA measured 9.6 to 26.7 ms); later shows stay as fast as today.
- No change to what the overlay draws (OverlayPanelTests stay green).
