## Goal

- `TopologyMonitor.reduce` is a pure reducer: a storm of raw display callbacks becomes ONE `readSnapshot` 200 ms after the last callback, then one `topologyChanged` plus one `resizePanels`, and Zone rectangles recomputed from fractions against the new frames.
- A nil UUID is re-read three times, one second apart on the Clock; a late success commits normally, three failures commit with a `.unstable` key that takes session-only Assignments and is never encoded (the document decoder rejects any non-UUID key).
- Mirror groups collapse to the master's key and a pick made while mirrored persists under it; a returning UUID restores its Assignment, a removed Display keeps its Assignment with no move effect, and `displayName`, `lastVisibleFrame`, `lastScale` are persisted for known UUIDs; the separate-Spaces notice fires once.
- `LayoutsPaneModel.rows` lists attached Displays, disconnected Displays (Copy Assignment to, Forget) and "not saved" unstable keys; `ScreenDisplayProvider` is the production `DisplayProvider` over NSScreen, `CGDisplayCreateUUIDFromDisplayID`, `CGDisplayMirrorsDisplay`, the AppKit screen-parameters notification and the CoreGraphics reconfiguration callback.

```swift
public enum DisplayKey: Hashable, Sendable { case uuid(String), unstable(String) }     // unstable: session only, never encoded
public struct PersistentDisplayKey: Hashable, Codable, Sendable { public let uuid: String }  // decoder rejects non-UUID (AC-123)
public struct DisplaySnapshot: Hashable, Sendable { public var key: DisplayKey; public var frame: CGRect; public var visibleFrame: CGRect; public var scale: Double
  public var isMain: Bool; public var mirrorOf: DisplayKey?; public var name: String; public var resolution: CGSize }
public struct TopologySnapshot: Hashable, Sendable { public var displays: [DisplaySnapshot]; public var separateSpaces: Bool; public var primaryFrame: CGRect
  public func display(_ key: DisplayKey) -> DisplaySnapshot? }
public struct Assignment: Hashable, Codable, Sendable { public var layout: LayoutID; public var displayName: String; public var lastVisibleFrame: CGRect
  public var lastScale: Double; public var lastSeen: Date? }
public enum NoticeFlag: String, Codable, Sendable { case modifiersCoerced, preferencesCoerced, separateSpacesOff }
public enum TimerID: String, Codable, Sendable { case trustPoll, healthTick, suspectResolve, relaunchGate, deadTapRetry, nilUUIDRetry, topologyDebounce, frameSample, unresponsiveCooldown }
public enum AssignmentLookup { public static func layoutID(for key: DisplayKey, in assignments: [String: Assignment], session: [DisplayKey: LayoutID]) -> LayoutID }  // default builtin:priorityGrid:3
public enum RawDisplayChange: Hashable, Sendable { case reconfiguration, screenParameters, activeSpace, wake }
public protocol DisplayProvider: Sendable {   // Production: ScreenDisplayProvider. Fake: FakeDisplayProvider
  func snapshot() -> TopologySnapshot; var changes: AsyncStream<RawDisplayChange> { get } }   // fresh read; nil uuid -> .unstable after retries
public enum TopologyEvent: Hashable, Sendable { case raw(RawDisplayChange), snapshot(TopologySnapshot, nilUUIDs: Int), timer(TimerID), assignmentPicked(DisplayKey, LayoutID) }
public enum TopologyEffect: Hashable, Sendable { case schedule(TimerID, TimeInterval), cancel(TimerID), readSnapshot, topologyChanged(TopologySnapshot), resizePanels(TopologySnapshot)
  case persistAssignment(PersistentDisplayKey, Assignment), sessionAssignment(DisplayKey, LayoutID), notice(NoticeFlag) }
public struct TopologyState: Hashable, Sendable { public var current: TopologySnapshot?; public var previous: TopologySnapshot?; public var uuidRetries: Int; public var session: [DisplayKey: LayoutID]; public var noticed: Set<NoticeFlag> }
public enum TopologyMonitor { public static func reduce(_ s: TopologyState, _ e: TopologyEvent, assignments: [String: Assignment], now: TimeInterval) -> (TopologyState, [TopologyEffect]) }  // mirror -> master key (AC-122)
public struct LayoutsPaneModel: Hashable, Sendable { public enum Row: Hashable, Sendable { case attached(DisplaySnapshot, LayoutID, unstable: Bool), disconnected(key: String, Assignment, copyTargets: [DisplayKey]) }
  public static func rows(_ t: TopologySnapshot, assignments: [String: Assignment], session: [DisplayKey: LayoutID]) -> [Row] }
```

## Behaviour decisions (the contract is silent; follow these, note any deviation in the ledger)

Reducer. `now` is unused. Timers other than `topologyDebounce` and `nilUUIDRetry` are ignored (state unchanged, no effects).
- `.raw(_)` (every case): `[.cancel(.nilUUIDRetry), .cancel(.topologyDebounce), .schedule(.topologyDebounce, Constants.topologyDebounce)]` and `uuidRetries = 0`. Trailing-edge debounce; the driver turns `.schedule` into one Clock timer per ID, replacing any pending one.
- `.timer(.topologyDebounce)` and `.timer(.nilUUIDRetry)` each return `[.readSnapshot]`.
- `.snapshot(s, nilUUIDs: n)` with `n > 0` and `uuidRetries < 3`: `uuidRetries += 1`, effects `[.schedule(.nilUUIDRetry, 1.0)]`, nothing committed. With `n == 0`, or `n > 0` and `uuidRetries == 3` (initial read plus three retries = four reads), COMMIT and reset `uuidRetries = 0`.
- COMMIT: (1) collapse mirrors: drop every Display whose `mirrorOf` names a Display present in the snapshot; record member -> master in `state.mirrorMaster`; keep the master's `DisplaySnapshot` unchanged. A `mirrorOf` naming an absent Display is left as is. (2) If the collapsed snapshot equals `state.current`, return no effects. Otherwise `previous = current`, `current = collapsed`, effects in this order: `.notice(.separateSpacesOff)` (only if `!separateSpaces` and the flag is not in `noticed`; insert it), then `.persistAssignment` for each changed record (below), then `.topologyChanged(collapsed)`, then `.resizePanels(collapsed)`.
- Metadata persist: for each Display with a `.uuid(s)` key and `assignments[s] != nil`, if `displayName`, `lastVisibleFrame` or `lastScale` differs from the Display, emit `.persistAssignment(PersistentDisplayKey(uuid: s), updated)` with `layout` and `lastSeen` untouched (the app stamps `lastSeen` when it writes). A UUID with no record gets nothing (default layout, no write). `.unstable` keys never produce `.persistAssignment`.
- Removed Display: no effect mentions it; the reducer never deletes or edits its record. There is NO move or re-snap effect case (ADR-0014); assert the effect list holds only the declared cases.
- `.assignmentPicked(key, layout)`: map `key` through `mirrorMaster` first. `.uuid(s)`: `.persistAssignment(PersistentDisplayKey(uuid: s), Assignment(layout, displayName, lastVisibleFrame, lastScale from the current Display, else from the existing record, lastSeen: existing?.lastSeen))`. `.unstable`: set `state.session[key] = layout` and emit `.sessionAssignment(key, layout)`, never persist. A UUID pick does not touch `session`.
- Notice persistence: the caller seeds `noticed` from `Preferences.notices` at launch and writes it back on `.notice`; the reducer only guarantees once per `noticed` set.
- First snapshot at launch and `forceTopologySnapshot` bypass the debounce: the driver feeds `.snapshot(provider.snapshot(), nilUUIDs:)` directly.

Provider. Unstable key strings: `"nil:<CGDirectDisplayID>"` when the UUID is nil (counted in `nilUUIDs`, retried), `"dup:<uuid>#<CGDirectDisplayID>"` for EACH of two attached Displays that resolve to the same UUID (not counted, never retried; both are "not saved"). UUID strings are uppercase.
- Frames stay in AppKit space (`NSScreen.frame`, `visibleFrame`); no conversion in the provider. `isMain` is `NSScreen.screens[0]` (the menu-bar Display), NOT `NSScreen.main`. `primaryFrame = screens[0].frame`. `separateSpaces = NSScreen.screensHaveSeparateSpaces`. `name = localizedName`; `resolution` = current mode pixel size, falling back to `frame.size * scale`; `scale = backingScaleFactor`.
- `mirrorOf`: `CGDisplayMirrorsDisplay(id)`; 0 means none, else the master's key (looked up among the same screens; absent master -> nil).
- `snapshot()` is nonisolated and sync: use `MainActor.assumeIsolated` on the main thread, else `DispatchQueue.main.sync`.
- `changes` yields `.reconfiguration` from `CGDisplayRegisterReconfigurationCallback` (ignore calls with `.beginConfigurationFlag`; never reconfigure inside it) and `.screenParameters` from `NSApplication.didChangeScreenParametersNotification`. On stream termination, remove both. No `.activeSpace` or `.wake` here (the shell owns those).

Pane. `rows(t, assignments:, session:)`: attached rows first in snapshot order, `.attached(display, AssignmentLookup.layoutID(...), unstable: key is .unstable)`; then one `.disconnected(key:, record, copyTargets:)` per `assignments` key that matches no attached `.uuid`, sorted by `displayName` then key; `copyTargets` = attached `.uuid` keys in snapshot order (an unstable target is excluded: a copy there would not be saved). A mirror member dropped by the collapse therefore appears as disconnected; accept it and note it in the ledger. The model supplies data and titles only; the buttons that perform Copy and Forget belong to the Settings ticket.
