# T13: WindowActor timeouts and production AX adapters: AXWindowSystem, AXPermissionProbe, AXObserver notices

Kind: build. Blocked by: T01, T06. Estimate: 120000 tokens. Branch: ticket/T13.
Protocol: WindowSystem, PermissionProbe (production AXWindowSystem, AXPermissionProbe). Fake: FakeWindowSystem consumed. Tests: WindowActorTests, FrameWriteResultTests.
Only place `CoordinateSpace.axRect`/`appKitRect` may be called outside CoordinateSpace and tests. No titles are read (LI-003).

## Goal

- `AXWindowSystem` implements every `WindowSystem` method, all on `@WindowActor`. `setTimeouts` calls `AXUIElementSetMessagingTimeout` with 0.25 s on each app/window element it uses and 1 s on the system-wide element (process-wide).
- AX errors are typed: CannotComplete becomes `timedOut`, InvalidUIElement becomes `elementGone`, APIDisabled becomes `apiDisabled`, anything else `refused(rawValue)`, for both `AXRead` and `AXStatus`.
- `frames(_:)` reads many windows in one pass; `facts(_:)` builds `WindowFacts` from subrole, `AXFullScreen` and `AXUIElementIsAttributeSettable`; Enhanced UI is read and written on the app element; `element(at:)` hit-tests with a smallest-window fallback.
- `AXObserverBridge` runs `AXObserver`s on one dedicated thread (SPK-013) and feeds `notices()` (`AsyncStream<AXNotice>`) with `destroyed` and `appTerminated`.
- `AXPermissionProbe` wraps `AXIsProcessTrusted` (never prompts), the System Settings URL and the launched-at-login flag.
- `WindowActor` declares the global actor and a launch helper that applies the timeouts; `WindowActorTests.timeoutsSetAtLaunch` proves it against the fake, and `FrameWriteResultTests` holds the compile-time exhaustive switch.

## ADRs

- ADR-0015 All AX calls run on a dedicated WindowActor with a 250 ms messaging timeout; UI on MainActor. Amendment 2026-10-24 (C7): a second consecutive timeout against the same app aborts the current Snap sequence (one retry only); a hung app costs at most 0.5 s on the serial actor. This adapter only reports `timedOut`; the retry/cooldown logic lives in the FrameWriter (another ticket). Never loop on a timeout inside `AXWindowSystem`.
- ADR-0022 Frame writes go size, position, size; read back; toggle AXEnhancedUserInterface off during the write. Amendment (C6): no behavior change; the toggle/restore policy lives in `EnhancedUIRecovery` (another ticket). This adapter only exposes `enhancedUI(pid:)` and `setEnhancedUI(_:pid:)`; absent attribute reads as `.value(nil)`.
- ADR-0020 Accessibility is the only TCC permission Zones asks for. Consequence: no window titles, so never read `kAXTitle`/`kAXDescription`/owner names.
- ADR-0021 One onboarding window; poll AXIsProcessTrusted; badge and re-onboard on revocation. Amendment (C5): revocation is derived from runtime signals; an `apiDisabled` result from any AX call moves granted to suspect. So map APIDisabled faithfully, never cache "trusted", and `isTrusted()` must call `AXIsProcessTrusted()` each time.
- ADR-0006 Drag detection: mouse events drive the gesture, AX frame polling confirms a move. AX moved/resized notifications are bookkeeping only; this ticket does not subscribe to them.
- ADR-0002 One root Package.swift with ZonesCore, ZonesLayout, ZonesWindowing. Adapters go under `Sources/ZonesWindowing/Adapters/`.

Design decisions made here (follow them; note any deviation in the ledger):
- Pure helpers, internal, testable without `import ApplicationServices` in tests: `AXStatus(axErrorCode: Int32)` and `AXRead<T>.failure(axErrorCode:)`. Codes: 0 ok, -25204 CannotComplete to timedOut, -25202 InvalidUIElement to elementGone, -25211 APIDisabled to apiDisabled, any other `refused(code)`. `Subrole(axSubrole: String?, axRole: String?)`: AXStandardWindow standard, AXDialog dialog, AXSystemDialog systemDialog, AXSystemFloatingWindow systemFloatingWindow, AXFloatingWindow floating, role AXSheet sheet, role AXPopover popover, else unknown. `AXGeometry` helpers that call `CoordinateSpace` (the only callers).
- Handles: every handle given out sets the per-app timeout on its element, caches nothing that survives its `WindowHandle`, and registers a destroyed subscription with the bridge (idempotent per key; ignore NotificationAlreadyRegistered). `WindowKey(pid:, elementHash: Int(CFHash(element)))`.
- `frame(_:)`: one `AXUIElementCopyMultipleAttributeValues` for position and size, `AXValueGetValue` into CGPoint/CGSize, then `CoordinateSpace.appKitRect`. `frames(_:)`: loop that call over the handles inside one `@WindowActor` turn; after a `timedOut` for a pid, mark that pid's remaining handles `timedOut` without calling (a hung app costs one timeout, not N).
- `setPosition(p, h)`: `p` is the AppKit origin of the window rect. Read the window's current size, convert `CGRect(origin: p, size: size)` with `axRect`, write the resulting origin with `kAXPositionAttribute`. `setSize` writes `kAXSizeAttribute` directly (no flip).
- `element(at:)`: convert the point with `axRect` of a zero-size rect, `AXUIElementCopyElementAtPosition(systemWide, Float, Float)`, climb `kAXWindowAttribute` or `kAXParentAttribute` (max 8 levels) to role `AXWindow`. Fallback when the hit is not a window or the call fails: `AXUIElementGetPid` of the hit element, then the smallest window of that pid whose frame contains the point. Menu bar, Dock and desktop hits return nil. Never read a title.
- `facts(_:)`: role and subrole strings, `"AXFullScreen"` bool (absent means false), `AXUIElementIsAttributeSettable` for position and size.
- `enhancedUI(pid:)`: `AXUIElementCreateApplication(pid)`, attribute `"AXEnhancedUserInterface"`; attributeUnsupported/noValue means `.value(nil)`. `setEnhancedUI` writes a `CFBoolean`.
- `trivialRead()`: copy one attribute (for example `kAXFocusedApplicationAttribute`) from `AXUIElementCreateSystemWide()`; success and noValue both map to `.ok`.
- `AXObserverBridge`: one `Thread` named `Zones.AXObserver`, started lazily, running `CFRunLoopRun()` with a keep-alive source or far-future timer so the loop never exits while idle (SPK-013). All `AXObserverCreate` and `AXObserverAddNotification` calls are marshalled onto that run loop (`CFRunLoopPerformBlock` plus `CFRunLoopWakeUp`). One observer per pid; add `kAXUIElementDestroyedNotification` per window with a refcon box holding the `WindowKey` (do not hash a destroyed element). `appTerminated(pid)` comes from `NSWorkspace.didTerminateApplicationNotification`; it also removes that pid's observer. Do not emit `moved` or `apiDisabled` in this ticket. Expose an internal `emit(_:)` so tests can drive the stream. `notices()` is `nonisolated` and returns a new stream per call; the continuations live in a lock.
- Sendable without new `@unchecked Sendable` (AC-161 allows exactly one, on `WindowHandle`): keep state in `OSAllocatedUnfairLock`, use `OSAllocatedUnfairLock(uncheckedState:)` for non-Sendable AX or CF values, and make classes `final` with only `let` Sendable stored properties.
- `AXPermissionProbe`: `isTrusted()` returns `AXIsProcessTrusted()` (never `AXIsProcessTrustedWithOptions` with the prompt option). `static let settingsURL = URL(string: "x-apple.systempreferences:com.apple.preference.security?Privacy_Accessibility")!` opened by `NSWorkspace.shared.open` in the `@MainActor` method. `launchedAtLogin` is a stored `let` set in `init(launchedAtLogin: Bool? = nil)`; when nil, read it once from `NSAppleEventManager.shared().currentAppleEvent?.paramDescriptor(forKeyword: AEKeyword(keyAEPropData))?.enumCodeValue == AEKeyword(keyAELaunchedAsLogInItem)`. The composition root (not this ticket; App/ is untouched) must construct the probe inside `applicationDidFinishLaunching`.

## Test plan

No AC in this ticket is manual; the live-AX behaviours (real hit-test, real observer callbacks, idle 60 s) cannot run in `swift test` and are covered by SPK-013 and by SPK-010 elsewhere, so give them an implementation and a ledger note only.

2. `WindowActorTests.timeoutsSetAtLaunch` (WindowActor, WindowSystem, Constants). Create `FakeWindowSystem`, run `WindowActor.applyLaunchTimeouts(to:)`, assert the fake recorded exactly one `setTimeouts` call with perApp `0.25` and processWide `1.0`, and that those equal `Constants.perAppTimeout` and `Constants.processTimeout`.
3. `AXMappingTests.statusFromAXErrorCode` (AXStatus, AXRead). Table: 0 ok, -25204 timedOut, -25202 elementGone, -25211 apiDisabled, -25205 refused(-25205), -25212 refused(-25212). Same table for `AXRead<CGRect>` failure.
4. `AXMappingTests.subroleMapping` (Subrole). Each AX subrole/role string maps as in the design list; nil and unknown strings map to `unknown`.
5. `AXMappingTests.coordinateRoundTrip` (CoordinateSpace). `AXGeometry` converts an AppKit rect to AX and back with `primaryFrame` of a 1440x900 primary and of a secondary Display above it (negative AX y); assert identity round trip and that the AX y of a window flush with the top of the primary is 0. Property form: 200 seeded random rects via the in-house generator (ADR-0016, `Generator` in ZonesTestSupport; read its API first) round-trip within `Constants.frameTolerance`.
6. `AXObserverBridgeTests.fanOut` (AXNotice). Two `notices()` streams both receive `emit(.destroyed(key))` then `emit(.appTerminated(42))` in order; a stream created after an emit does not replay it.
7. `AXPermissionProbeTests.probeValues` (PermissionProbe). `launchedAtLogin` honours the injected value; `settingsURL.absoluteString` equals the exact string above; `isTrusted()` is callable (do not assert its value).
8. `AXWindowSystemTests.conformsAndTimeoutsDoNotCrash` (WindowSystem). Instantiate `AXWindowSystem`, call `setTimeouts(perApp: 0.25, processWide: 1.0)` and `trivialRead()` on `@WindowActor`; assert the result is one of `.ok`, `.apiDisabled`, `.timedOut` (CI may be untrusted). No assertions on other apps' windows.
9. Implementation slices needing no new assertion (commit each, ledger line each): `frames` batching and the per-pid short-circuit; `element(at:)` fallback; `enhancedUI` read/write; observer thread keep-alive; `NSWorkspace` termination feed.
