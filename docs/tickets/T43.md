# T43: QA fix: editor toolbar pop-up and sliders expose accessibility labels (AC-139)

Kind: fix (QA round 1). Blocked by T35 (all done). Estimate 40k tokens. Area: App/Editor. Protocol: EditorToolbar (edit). Fake: none needed (AppKit view test).

## Goal

- The editor toolbar Display pop-up and the Margin and Gap sliders expose non-empty AX labels `Display`, `Margin`, `Gap` on the element AppKit actually exposes (the cell), or are linked to their visible label text fields with `setAccessibilityTitleUIElement`.
- Slider AX values read as the point value with unit (e.g. `8 points`), if the current code exposes a bare number keep the number but make sure it updates when the value changes.
- No other editor behavior changes.

## QA findings this ticket closes (verbatim evidence)

#### QA-1.7: Editor toolbar Display pop-up and Margin/Gap sliders expose an empty accessibility label (label set on the NSControl, but the exposed AX element is the cell)
- Where: `App/Editor/EditorToolbar.swift:91`
- Evidence: In-process AX walk of the editor window content (a11y-run3.log / run4): `A11Y[editor] d=1 role=AXPopUpButton elem=true label='' title='' value='Built-in' type=NSPopUpButtonCell`, `role=AXSlider label='' title='' value='0' type=NSSliderCell` (x2), summary `elements=13 unlabeled=3`. Getters (run4): `A11Y[editor.popup] viewLabel='Display' viewElem=false cellLabel='' cellTitle='' unignored=["NSPopUpButtonCell"]`, `A11Y[editor.slider] viewLabel='Margin' viewElem=false cellLabel='' unignored=["NSSliderCell"]`, same for Gap. The NSControl is ignored (viewElem=false), the cell is the unignored element, and `setAccessibilityLabel` on the control (lines 91, 111, 112) does not reach the cell; VoiceOver would announce 'Built-in, pop up button' and '0, slider' with no name. The Template pull-down is fine only because its first item title 'Template' becomes the AX title; the 'Margin 0'/'Gap 0' static texts are separate elements, not labels of the sliders.
- Repro: Run the archived scratch suite (see finding 1) and grep `A11Y-UNLABELED\[editor\]` (3 lines) and `A11Y\[editor.popup\]|A11Y\[editor.slider\]`.
- Fix hint (verifiers agreed 2/3): Set the label where AppKit reads it: `displayPopup.cell?.setAccessibilityLabel("Display")`, `marginSlider.cell?.setAccessibilityLabel("Margin")`, `gapSlider.cell?.setAccessibilityLabel("Gap")` (or use `setAccessibilityTitleUIElement` pointing at the marginLabel/gapLabel text fields).
