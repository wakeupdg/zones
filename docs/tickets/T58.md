# T58: Every Zones chord = Activation Modifier + Span Modifier + key

Kind: feature, spec change (orchestrator, from the human run on 2026-10-24, AC-106). Blocked by: none.

## Evidence (user report, 10:58 PM PT)
- The default Send to Zone 1 chord, Control+Option+1 (ADR-0010, AC-097), clashes with a MacParakeet shortcut on the tester's Mac.
- The user's rule: "every chord references these two variables (activation and span) so we stay consistent as we change these". Today the 14 default chords are a fixed Control+Option prefix (`Preferences.defaultShortcuts`, Sources/ZonesCore/Preferences.swift), stored per chord with their own modifiers.
- Tester's stored preferences: activation `control`, span `command` → the chords become Control+Command+key.

## Goal
1. The modifiers of every Zones chord are derived, never stored: `activationModifier ∪ spanModifier`. A `Shortcut` stores only its action and key. Defaults keep the keys of ADR-0010 (1..9, Right, Left, R, E, Comma).
2. Changing the Activation or Span Modifier in General re-registers all hotkeys at once with the new prefix (same `HotkeyRegistrar` path; AC-104 rule: a chord whose registration fails keeps its previous registration and shows the failure in the Shortcuts pane).
3. Shortcuts pane: the recorder records the KEY only. Each row shows the fixed prefix as key caps (read-only, from General) plus the recorded key. Duplicate keys are a conflict (AC-103 duplicate rule).
4. Validation (AC-102 moves from the chord to the pair): the pair must contain Command or Control. General refuses a pick that breaks this (for example Shift + Option) with one line of help; extend `Preferences` coercion and its `.modifiersCoerced` notice for stored data that breaks it.
5. Migration: bump the preferences schema. A stored chord keeps its key and drops its modifiers. A stored custom chord whose modifiers differ from the old default prefix is still reduced to its key; log one line per changed chord.
6. Spec: amend ADR-0010 (prefix = Activation + Span) and AC-097, AC-102, AC-103, AC-106, AC-107 statements through challenge C14 in LOCKED-SPEC.md. Manual AC text names "the Editor chord" and "the Send to Zone 1 chord" instead of fixed keys. README shortcut table and CHANGELOG ("Changed") follow.
