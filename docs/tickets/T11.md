# T11: Diagnostics and logger: Log facade, bounded EventRing, skip counting, DiagnosticsReport with preview-before-copy

Kind: build. Blocked by: T01 (root Package.swift, scripts/q.sh, ZonesTestSupport skeleton). Estimate: 100k tokens.

## Goal
- `Log` facade in ZonesCore with one `LogCategory` per module, a `LogSink` protocol, `UnifiedLogSink` (os.Logger, production) and `ArrayLogSink` (tests).
- `EventRing` holds at most 200 events (`Constants.ringCapacity`) and keeps `skipCounts` grouped by bundle identifier; `Log.skip` emits exactly one event per skip.
- `DiagnosticsReport` carries version, build, signingIdentity (or "ad-hoc"), macOS, permission and tap state, Displays (key and frames), Assignments, Preferences, the last 200 events and skip counts. `LogEvent` has no title field, ever (LI-003).
- `Diagnostics.report(...)` builds it, `render()` prints it as text, and `DiagnosticsEffect` ordering is preview first, then copy.
- `BundleInfo` reads version, build and the signing identity from the running bundle (common name of the leaf signing certificate, else "ad-hoc").

## Design decisions (settled here; do not reopen)
- `Log` is `final class Log: Sendable`; its mutable state (sink, ring) sits in `OSAllocatedUnfairLock`. `event(_:)` appends to the ring and calls the sink once. `ring()` returns a copy.
- `EventRing.append` drops the oldest event at capacity. `skipCounts` is cumulative: appending an event with `skip != nil` increments `skipCounts[bundleID ?? "unknown"][skip]`; eviction never decrements it. Record this choice in the ledger.
- `Log.skip` builds one `LogEvent`: `time = ProcessInfo.processInfo.systemUptime`, `level = .info`, `message = "skip " + reason.rawValue`, `bundleID = ref?.bundleID`, `pid = ref?.pid` (Int32), `skip = reason`. Never put a window title, document name or owner name in `message` (LI-003, ADR-0020).
- `UnifiedLogSink` maps `LogCategory` to one `os.Logger` (subsystem constant "Zones", category = `rawValue`) and `LogLevel` to `.debug/.info/.notice/.error`; messages logged with `privacy: .public` because they never carry titles.
- `ArrayLogSink` is a `final class` with `OSAllocatedUnfairLock<[LogEvent]>`, `var events: [LogEvent]`. Define it in `Sources/ZonesCore/Log.swift` unless `Sources/ZonesTestSupport/Fakes/` already has it (then reuse that one, do not duplicate).
- Report `permission` and `tap` fields are `String(describing:)` of `PermissionState` and `TapState`. `displays` comes from `topology?.displays` (empty when nil); `DisplaySnapshotReport.key` is the `DisplayKey` payload string; `assignments` keys are already strings.
- `render()` is deterministic plain text, one `label: value` line per scalar, with the exact line `signingIdentity: <value>`. Sections `displays`, `assignments` (sorted by key), `preferences`, `events` (last 200, oldest first, one line each: `time category level message [bundleID pid skip]`) and `skipCounts` (bundle ids sorted, reasons sorted by rawValue).

## Test plan
Swift Testing; every test is a method of `DiagnosticsTests` so `--filter DiagnosticsTests.<name>` works. All four ACs are auto; none is manual. None calls for a property test. Slices in order, each red first:
1. `ringBoundedAndSinks` (AC-169). Contract: EventRing, Log, LogCategory, LogSink. Asserts: appending 500 events leaves `events.count == 200` and the last 200 in order; `EventRing(capacity: 3)` keeps 3; `LogCategory.allCases` equals the 12 contract cases; a `Log()` with an `ArrayLogSink` installed gets each `event(_:)` once and `ring().events` matches; `UnifiedLogSink().write(...)` runs for every category and level without crashing (the os log itself is not read back).
2. `skipReasonsCounted` (AC-155). Contract: Log.skip, SkipReason, EventRing.skipCounts. Asserts: for every `SkipReason.allCases` one skip adds exactly one sink event with that `skip`, the ref's bundleID and pid, and the ring count for that bundle and reason is 1; a second skip makes it 2; two bundle ids count separately; `ref == nil` counts under "unknown"; no event message contains anything beyond `skip <rawValue>`; the static `Log.skip` forwards to `Log.shared` (the only test using it; install an ArrayLogSink and read back).
3. `reportNamesSigningIdentity` (AC-015). Contract: BundleInfo, DiagnosticsReport.render. Asserts: `make` with commonName "Developer ID Application: Example (TEAM123)" gives that `signingIdentity`, and `render()` contains the exact line `signingIdentity: Developer ID Application: Example (TEAM123)`; commonName nil or empty gives "ad-hoc" and the line `signingIdentity: ad-hoc`; version and build come from `CFBundleShortVersionString` and `CFBundleVersion`; `BundleInfo.current()` returns a non-empty signingIdentity inside the test host.
4. `reportContentsAndPreviewFirst` (AC-154). Contract: Diagnostics.report, DiagnosticsReport, DiagnosticsEffect. Asserts: with a 3-display topology (Fixtures.threeDisplays if ZonesTestSupport has it, else build one by hand), two Assignments, default Preferences, a ring of 250 events with skips: the report has version, build, signingIdentity, macOS, permission and tap strings, 3 `DisplaySnapshotReport` entries with the right key, frame, visibleFrame and scale, the assignments, the preferences, exactly 200 events and the skip counts; `render()` contains every display key, every assignment key and every bundle id from skipCounts; topology nil gives zero displays; the report encodes to JSON whose `LogEvent` keys are exactly `time, category, level, message, bundleID, pid, skip` (no `title`, no `name`); `Diagnostics.effects(for:)` returns exactly two effects, `.preview(text)` at index 0 and `.copy(text)` at index 1, with identical text.
