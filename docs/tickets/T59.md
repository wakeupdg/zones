# T59: Hinted 16/32 px app icon for the macOS 14/15 fallback

Kind: fix (orchestrator, from the T57 report on 2026-10-24). Blocked by: T57 (needs `App/AppIcon.icon` merged).

## Evidence
- T57 ships `App/AppIcon.icon`. Xcode (actool) makes the macOS 14/15 flat fallback by itself: `AppIcon.icns` and flat AppIcon images 32..1024 px in `Assets.car`.
- That fallback is a plain downscale. At 16 px (and weakly at 32 px) the white glass tiles almost disappear on the cream body (light). The T57 brief already named this weak point (1.10:1 tile edge).
- Figma Section 6 has hinted frames made for this (file c1pMnDAGUn6jiXCu9yQp1I): light 128 `50:1662`, 32 `50:1672`, 16 `50:1679`; dark 128 `50:1686`, 32 `50:1696`, 16 `50:1703`.
- T57 builder: actool rejects an `AppIcon.appiconset` with the same name next to `AppIcon.icon`.

## Goal
1. On macOS 14/15 (and in any place that asks for the 16/32 px icon: Finder list view, Spotlight, menus), the app uses the hinted Figma frames, not the downscale.
2. On macOS 26+, the Liquid Glass `.icon` stays the icon (no change to the T57 render at Dock size).
3. Find the supported way first. Candidates, in order: actool options or an icon.json feature for per-size overrides; a differently named `.appiconset` used as `CFBundleIconFile` fallback while `CFBundleIconName` stays `AppIcon`; a post-build step that replaces the 16/32 px members of `AppIcon.icns`. Give the evidence for the one you pick (Apple docs, actool help, or a test).

## Acceptance
- `assetutil --info` / `iconutil -c iconset` on the built app show that the 16 and 32 px (1x and 2x) images are the hinted Figma frames (compare pixels with the Figma exports).
- macOS 26 render (`NSWorkspace.shared.icon(forFile:)` at 512 px) is unchanged against the T57 build.
- `swift test` green; xcodegen + Debug xcodebuild green.

## Files expected
App/AppIcon.icon or App/Assets.xcassets (fallback set), project.yml, maybe a build script under scripts/, CHANGELOG.md.

## Builder setup
Session in a `scripts/wt.sh` worktree (see .claude/rules/builder-session-vs-subagent.md). Unsigned build (`ZONES_UNSIGNED=1`), no push, no merge, no keychain, no `/Applications`, never relaunch the running Zones app. Figma read-only.

## File split (T61 runs at the same time, added 2026-10-25)
- T59 OWNS: the fallback method (a second, differently named icon set in `App/Assets.xcassets`, or a build step under `scripts/`), `project.yml`, CHANGELOG line.
- T59 MUST NOT touch: `App/AppIcon.icon/icon.json` or the layer SVGs (T61 owns them). So candidate 1 (an icon.json per-size override) is out; use candidate 2 or 3.
- If T61 later changes the glow or lit zone, the hinted PNGs may be re-exported; the method stays.
