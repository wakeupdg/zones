# T12: Hit test, nearest zone, span union, label model, templates and built-in identifiers

Kind: build. Blocked by: T09 (LayoutMath, ZoneNumbering, Grid and the core value types exist). Estimate: 130000 tokens. Branch: ticket/T12.
Pure Swift in ZonesLayout. No AppKit views, no App/ edits, no protocols, no fakes.

## Goal

- `HitTest.hit(point, in: ResolvedLayout)` returns `.zone(n)` inside a Zone, `.nearest(n)` for any other point inside the visible frame (minimum edge distance, ties to the lower Zone Number), `.none` only outside the visible frame. `HitTest.display(at:in:)` maps a point to the `DisplayKey` of the Display whose frame holds it.
- `Span.rect(zones, in:)` is the bounding union of the named Zone frames, so Gaps between them are included.
- `LabelModel.labels(resolved, appearance:)` returns one `ZoneLabel` per Zone: text = Zone Number, outline contrasting 4.5 or better with the fill, `contentsScale` = Display scale, `noChord` true for numbers above 9.
- `Templates.builtInID/generate/all/duplicate` build Columns and Rows 2-5, Grid 4 and 9, Priority Grid 25/50/25, Focus (one leaf, surround 0.2). Ids are deterministic (`builtin:<camelCase>:<count>`), derived at load, never persisted. `LayoutValidator.validate` returns the first `LayoutFault` or nil.
- Done when TemplateTests.countsShapesAndNames, TemplateTests.focusIsOneCenteredZone, BuiltInLayoutTests.deterministicIdsAndDuplicate and the HitTest and Span unit cases are green. AC-080/081/063 belong to later tickets; this ticket only supplies and unit-tests the functions they call.

## Design decisions (settled here; ledger each one you apply)

- Hit order: inside any Zone frame (half-open: min edge in, max edge out; on a shared boundary the lower number wins) gives `.zone(n)`. Else inside the visible frame (closed on all four edges) gives `.nearest(n)`. Else `.none`.
- Edge distance to a rect: `hypot(max(minX-x, 0, x-maxX), max(minY-y, 0, y-maxY))`. Smallest wins; treat distances within `Constants.numberingEpsilon` as equal and pick the lower Zone Number.
- `display(at:)`: first non-mirrored display (`mirrorOf == nil`) in snapshot order whose `frame` contains the point (half-open); else nil. Uses `frame`, not `visibleFrame`, so the menu bar strip still belongs to its Display.
- `Span.rect`: union of the frames of the numbers present; numbers not in the layout are ignored; empty result is `.zero`. No margin or gap arithmetic: the union of frames already spans the Gaps.
- Label outline: black or white `RGBA` (a = 1), whichever has the higher WCAG contrast ratio with the opaque fill RGB (`Appearance.fill`, ignoring `opacity`, which is what "at any opacity" means). Relative luminance uses the sRGB linearization; ratio = (L1 + 0.05) / (L2 + 0.05). The worst case (mid gray) is about 4.58, so 4.5 always holds. Label `frame` = the Zone frame; `text` = `String(number)`; `contentsScale` = `r.scale`; `noChord` = number > 9.
- Template layout `name` = `Template.rawValue` exactly (no count suffix); ids and `builtIn` distinguish counts. `builtInID` = `"builtin:\(camelCase):\(count)"` with camelCase from the case name (columns, rows, grid, priorityGrid, focus). `all(insets:)` order: `Template.allCases`, each by `counts` ascending: 12 layouts total. Every built-in has `builtIn` set, `surround` zero except Focus, and the passed `insets`.
- Trees: Columns n = right-nested horizontal splits, k-th ratio `1/(n-k)`. Rows n = same with vertical. Grid 4 = vertical 1/2 of two horizontal 1/2 splits; Grid 9 = vertical 1/3 then 1/2 of rows of horizontal 1/3 then 1/2. Priority Grid = `split(horizontal, 0.25, leaf, split(horizontal, 2/3, leaf, leaf))`. Focus = `.leaf` with `Surround` of `Constants.focusSurround` on every side.
- `duplicate`: `id = newID`, `name = "\(l.name) copy"`, `builtIn = nil`, `insets = insets` argument (the current defaults), root and surround copied.
- `validate` precedence: `emptyName` (name empty after trimming whitespace), `surroundOutOfRange` (any side < 0 or > 0.45, or NaN), `ratioOutOfRange(path)` (first in depth-first order with ratio <= 0, >= 1 or NaN), `leafTooSmall(path)` (first leaf, depth-first, whose unit width or height is under `Constants.minFraction - 1e-9`). `overlap` is never produced (a tree cannot overlap); say so in a doc comment.
