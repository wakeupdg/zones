# T15: Snap service: write protocol, read-back truth, clamp follow-up, idempotence, timeout retry and AppHealth cooldown

Kind: build. Blocked by: T02 (fakes). Estimate: 140000 tokens. Branch: ticket/T15.
Protocol: FrameWriting (production FrameWriter). Fake: FakeWindowSystem and FakeClock (consumed, from ZonesTestSupport). Tests: SnapServiceTests, AppHealthTests.

## Goal

- `FrameWriter.write` issues setSize, setPosition, setSize, then reads the frame back, all on the `WindowActor`, and returns what the app accepted.
- A `timedOut` status is retried once immediately; a second timeout aborts the sequence (only the Enhanced UI restore follows), returns `timedOut`, and marks the pid unresponsive for 10 s on the Clock.
- `AppHealth` answers `isUnresponsive` during the cooldown and allows exactly one attempt after it (`consumeRetry`).
- `SnapService.execute` returns `noOp(sameFrame)` with no write when the target is within 1 pt of the current frame; on `clamped` it issues exactly one follow-up position write; the read-back frame is the recorded truth; it touches only the plan's handle.
- `sizeNotSettable` windows get position-only mode: no size write, setPosition at the target origin, read back.
- Enhanced UI toggling is stubbed through `EnhancedUIRecovery` hooks that T19 fills; keep the toggle-off / `defer` restore shape now.

public enum EnhancedUIPolicy: String, Codable, Sendable { case toggle, leave }
// Constants: perAppTimeout = 0.25, unresponsiveCooldown = 10.0, frameTolerance = 1.0 (all in ZonesCore Constants)

public protocol Clock: Sendable { var now: TimeInterval { get }   // monotonic seconds

  @WindowActor func enhancedUI(pid: pid_t) -> AXRead<Bool?>; @WindowActor func setEnhancedUI(_ on: Bool, pid: pid_t) -> AXStatus   // nil = attribute absent
  /* ...other members elided; not used here */ }

public protocol FrameWriting: Sendable {   // size, position, size, read back; Enhanced UI off/on with defer; retry once then abort

Design decisions this brief fixes (do not re-litigate):
- `WindowSystem` has one `frame(_:)` read, so "readPosition, readSize" is that single read. The fake logs `Call` cases per method (T02 brief: nested `Call` enum, one case per protocol method with its arguments). Assert the order `[setSize, setPosition, setSize, frame]` using the actual case names in `Sources/ZonesTestSupport/Fakes/FakeWindowSystem.swift`.
- Write sequence (`.full`): `setSize(target.size)`, `setPosition(target.origin)`, `setSize(target.size)`, `frame` read. `.positionOnly`: `setPosition(target.origin)` then `frame`; no size write.
- Result classification from the read-back `r`: `.applied(r)` when `r` matches `target` within `Constants.frameTolerance` per component (position-only: origin only); otherwise `.clamped(r)`. A non-timeout failed status maps to `.refused(code)` or `.elementGone`; stop the sequence there.
- Timeout: a `.timedOut` status or read repeats that same call once at once; a second `.timedOut` aborts, calls `health.markUnresponsive(h.pid, now: now)` and returns `.timedOut`. Total fake calls on a double timeout = the first call + its one retry, nothing after (assert the count).
- Cooldown gate at the top of `write`: if `health.isUnresponsive(pid, now)` return `.timedOut` with zero AX calls. `AppHealth` stores per pid an `until = now + Constants.unresponsiveCooldown` and a retry-pending flag; `isUnresponsive` is true while `now < until`; after `until`, `consumeRetry` returns true exactly once, then false until the pid is marked again.
- Enhanced UI: `let restore = prepareEnhancedUI(pid, policy)` before the writes (no-op stub when policy is `.leave`, attribute absent or already off), restore via `defer` on every path including the timeout abort. T19 fills the hook bodies; do not write the recovery store logic.
- `SnapService.execute`: (1) read `system.frame(handle)` once; on `.value(cur)` within tolerance of `plan.target` (position-only: origin only) return `SnapOutcome(result: .noOp(.sameFrame), readBack: cur)` with zero writes; a failed read maps to the matching `FrameWriteResult` with `readBack: nil`. (2) call `writer.write(plan.target, mode: plan.mode, to: handle, ...)`. (3) on `.clamped(r)` call `writer.write(CGRect(origin: plan.target.origin, size: r.size), mode: .positionOnly, ...)` exactly once and return its read-back as `readBack`, keeping the `.clamped` result so the caller can log the clamp (the log effect and `OriginalFrameRegistry.recordSnap` belong to the caller ticket; this service only guarantees `readBack` is the truth). Never write to any handle other than the one passed in.
- No `@unchecked Sendable` anywhere; `AppHealth` is a plain value type passed `inout`.

## ADRs

- 0015 All AX calls run on a dedicated WindowActor with a 250 ms messaging timeout; UI on MainActor. Amendment (C7): a second consecutive timeout aborts the Snap sequence (one retry only); worst case 0.5 s; the app enters a short unresponsive cooldown.
- 0018 Besides per-app exclusions, Zones skips windows it cannot or should not move. Amendment (C4): sizeNotSettable windows with settable position get a position-only Snap at the Zone's top-left with no size write; unresponsive pids are skipped in phase 1.
- 0022 Frame writes go size, position, size; read back; toggle AXEnhancedUserInterface off during the write. Amendment (C6): restore in a `defer` on every path; skip the toggle when the attribute is absent or already off; policy toggle (default) or leave.
- 0002 One root Package.swift with ZonesCore, ZonesLayout, ZonesWindowing (all three Snap files live in ZonesWindowing).
