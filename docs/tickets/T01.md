```swift
public final class WindowHandle: @unchecked Sendable, Hashable   // THE one unchecked box (AC-161); wraps AXUIElement
@globalActor public actor WindowActor { public static let shared: WindowActor }
public protocol Clock: Sendable { var now: TimeInterval { get }
```

Rules that apply to the whole transcription:
- Every public struct needs an explicit `public init` with all stored properties (the synthesized one is internal and other targets cannot call it). Every public type is `Sendable`.
- `import Foundation` is enough for CGRect, CGPoint, CGSize and pid_t. Only `Seams/WindowHandle.swift` may `import ApplicationServices` (for AXUIElement). `App/` must not import it, and nothing under `App/` may contain `try!`, `as!` or `fatalError(` (AC-162 gate comes later).
- `Clock` shadows Swift's `Clock`; that is intended. Inside any file that imports ZonesCore it resolves to ours.
- `WindowHandle`: `key = WindowKey(pid: pid, elementHash: Int(CFHash(element)))`; `==` and `hash` use `key`.
