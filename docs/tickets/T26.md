# T26: Overlay model: panel geometry, fills, highlight styles, labels, accessibility options

Kind: build. Blocked by: T12 (LabelModel, HitTest, Span exist). Estimate: 100000 tokens. Branch: ticket/T26.
Pure Swift in ZonesWindowing/Overlay. No AppKit, no CALayer, no App/ edits, no protocol, no fake. The NSPanel half (AC-058 `OverlayPanelTests`) is T31.

## Goal

- `OverlayModel.panels` turns an `OverlayScene` into one `PanelModel` per Display: panel `frame` is the full Display frame, every `ZoneDrawing.rect` is a Zone frame (inside that Display's visible frame), `label` comes from `LabelModel` (text = Zone Number, 4.5:1 outline, `contentsScale` = that Display's scale).
- Fill alpha equals the Appearance opacity. At opacity 0.10 the highlight style differs from idle by at least 0.25 alpha and also by color. A secondary style (suspended Span) and a dim style exist.
- Under `reduceTransparency`: fills are solid and a suspended Span is an outline (`spanOutline`). Under `reduceMotion`: `animationDuration` is nil.
- `OverlayModel.apply(Highlight, to:)` returns new panels with each Zone repainted as primary, secondary, dim or idle. Pure, deterministic, no side effects.
- Done when OverlayModelTests (zonesWithinVisibleFrame, highlightDistinctAtLowOpacity, labelsLegibleAndScaled, accessibilityOptions) is green and the full suite stays green.

### Settled decisions (ledger each as `decision | ...` when applied)

1. CONTRACT GAP: `OverlayScene` carries `[ResolvedLayout]` (visibleFrame, scale) but no full Display frame, and the fixed `panels(_ s: OverlayScene)` has no topology. Keep that exact signature (panel `frame` falls back to `layout.visibleFrame`, doc-comment it as a fallback) AND add the overload `public static func panels(_ s: OverlayScene, topology: TopologySnapshot) -> [PanelModel]` that looks up `topology.display(layout.display)?.frame` (fallback visibleFrame when absent). Both share one private implementation. Tests call the topology overload. The T31 presenter must call the overload; say so in the ledger.
2. Output order = `scene.layouts` order, one panel per layout, `PanelModel.display = layout.display`. Zones in each panel sorted by number. `ZoneDrawing.rect = Zone.frame` (AppKit global coordinates; the panel view converts with `CoordinateSpace.panelLocal`). `ZoneDrawing.label` = the `LabelModel.labels(layout, appearance:)` entry with the same number; `ZoneDrawing.fill` starts as `style.idle`.
3. Colors, with `f = appearance.fill`, `o = appearance.opacity` clamped to 0...1, `mix(c, t, k)` = per-channel linear blend, `ext` = white if relative luminance of `f` < 0.5 else black:
   - transparent mode (reduceTransparency false): `idle = f` with `a = o`. `highlight = mix(f, ext, 0.35)` with `a = min(1, max(o + 0.30, 0.40))`. `secondary` = highlight RGB with `a = (idle.a + highlight.a) / 2` (visibly dimmer than highlight). `dim = f` with `a = o * 0.4`.
   - reduceTransparency true: all four are solid (`a = 1`). `idle = f`; `highlight = mix(f, ext, 0.35)`; `dim = mix(f, black, 0.5)`; `secondary = highlight RGB` with `a = 0` and `spanOutline = true` (suspended Zones are stroked, not filled; the presenter strokes any Zone whose fill equals `style.secondary`).
   - `spanOutline = options.reduceTransparency` for every panel, fixed at `panels` time (`apply` does not know the options and must leave `spanOutline` untouched).
   - `animationDuration = options.reduceMotion ? nil : OverlayModel.animationSeconds` where `public static let animationSeconds = 0.12` lives in OverlayModel.swift.
4. `apply(h, to:)`: if `h.dimAll`, every Zone on every panel gets `style.dim`. Else only the panel whose `display == h.display` (nil display: none) is repainted: number in `primary` gets `highlight`; else in `secondary` gets `secondary`; else `idle`. All other panels return to all-`idle`. `apply` never changes `frame`, `style`, `labels`, rects or zone order, and calling it twice with the same Highlight gives equal results.
5. KNOWN LIMIT (ledger it, do not solve it): `Highlight` has one `display`, so a Span suspended on Display A while the highlight sits on Display B cannot be drawn on A by `apply`. AC-085 (manual) and the reducer's choice of `Highlight.display` decide that later; return `blocked-needs-human` only if you find a contract line that contradicts rule 4.

## Test plan

Swift Testing (`@Test`, `#expect`). One red-green slice per commit: write the test, see it fail on an assertion (add a stub returning a wrong value first so a missing symbol is not the failure), then implement. Scene helper: `Fixtures.layouts(Fixtures.threeDisplays, Fixtures.nineZone)` (a dictionary: build `layouts` as `topology.displays.compactMap { dict[$0.key] }` to keep topology order), `Appearance(fill: RGBA(r: 0.2, g: 0.4, b: 0.9, a: 1), opacity: o, defaultInsets: Insets(margin: 0, gap: 0))`, `AccessibilityOptions(reduceTransparency: false, reduceMotion: false)` unless the case says otherwise.

1. zonesWithinVisibleFrame (AC-059; exercises OverlayModel.panels, Fixtures.threeDisplays). 3 panels in topology order; each `frame == display.frame` exactly; each has 9 zones numbered 1...9; every `rect` is inside that Display's `visibleFrame` (min/max edges within 1e-6); at least one fixture Display has `visibleFrame != frame` or, if none does, add a hand-built Display with a 25 pt menu-bar strip and assert panel frame is the larger rect while rects stay in the smaller one; negative-origin Displays pass. Also assert the contract-signature `panels(scene)` returns 3 panels using `visibleFrame` as fallback.
2. highlightDistinctAtLowOpacity (AC-042; exercises PanelStyle, OverlayModel.panels). For o in 0.10, 0.50, 1.0: `style.idle.a == o` within 1e-9 and every `ZoneDrawing.fill == style.idle`. At o = 0.10: `highlight.a - idle.a >= 0.25` AND `highlight` RGB differs from `idle` RGB; assert both. For every o: `secondary.a` lies strictly between `idle.a` and `highlight.a` unless `highlight.a == 1` and o == 1 (then `<=`), and `dim.a < idle.a`.
3. applyPaintsPrimarySecondaryDim (exercises OverlayModel.apply). Highlight display = D1, primary {3}, secondary {5, 7}: zone 3 fill == highlight, 5 and 7 == secondary, the rest idle; D2 and D3 panels all idle. `primary` wins over `secondary` for a shared number. `dimAll` true: every Zone on all panels == dim. `display: nil` with empty sets: everything idle. `apply` leaves `frame`, `style`, `spanOutline`, labels and rects unchanged; applying twice equals applying once; applying an empty Highlight after a painted one restores the `panels` output exactly.
4. labelsLegibleAndScaled (AC-063; exercises LabelModel via OverlayModel.panels). For o in 0.1, 0.5, 1.0, every Zone on every panel: `label.text == String(number)`, `label.number == number`, `label.contentsScale == that Display's scale` (the 2x Display gives 2.0, the others 1.0), and the WCAG ratio between `label.outline` and the opaque Appearance fill RGB (opacity ignored) is at least 4.5, computed by the test's own helper (sRGB linearize, ratio `(L1 + 0.05) / (L2 + 0.05)`). Repeat with a mid-gray fill (0.46, 0.46, 0.46), the worst case.
5. accessibilityOptions (AC-058 model half; exercises AccessibilityOptions, PanelStyle, PanelModel.spanOutline). Default options: `spanOutline == false`, `animationDuration == OverlayModel.animationSeconds`, `idle.a == o`. reduceMotion true only: `animationDuration == nil`, nothing else changes. reduceTransparency true (o = 0.10): `idle.a`, `highlight.a`, `dim.a` all 1, `secondary.a == 0`, `spanOutline == true` on every panel (also after `apply` with a secondary set), and highlight RGB still differs from idle RGB. Both true: both effects at once.
6. panelsAreDeterministicAndIsolated (property, ADR-0016; skip and ledger it if ZonesWindowingTests lacks ZonesTestSupport). For 100 `Generator(seed:)` layouts resolved onto the three Displays with random opacity in 0.05...1 and random option flags: calling `panels` twice gives equal arrays; every rect is inside its visibleFrame; `apply` of a random Highlight never changes geometry. Failure message via `Generator.failureMessage`.
